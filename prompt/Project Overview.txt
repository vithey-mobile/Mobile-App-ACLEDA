# Vithey App — Project Overview

**App:** Vithey App  
**Package:** `aub_connect_app`  
**Audience:** AUB students + youth users

This repository stores AI prompts and product/API specifications only. Generated code should be created later under:

- `vithey_app/` — Flutter app
- `vithey-backend/` — Spring Boot backend

```text
Acleda Mobile App/
```

## Build Order

1. DevOps: `Prompt Devops/v1/00-foundation-prompt.md`
   - For independent service DevOps, use `Prompt Devops/services/<service>/DEVOPS_PROMPT.md`
2. Backend: `Prompt Backend/infrastructure/SERVICE_PROMPT.md`
3. Backend services in order: gateway → auth → user-profile → file → content → career → finance → chat → notification → ai
4. Frontend screens: use `Prompt Frontend/Screen prompt/README.md`
5. API integration: `Prompt Frontend/api-intergration/00-api-intergration-prompt.md`

## API Rule

All frontend API integration content lives in:

```text
Prompt Frontend/api-intergration/
```

Do not create duplicate API integration prompt files in `reference/`, screen folders, or other locations.
