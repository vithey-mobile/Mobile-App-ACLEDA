## Assistant message (`assistant_message.dart`)

### Layout

```text
Column(
  crossAxisAlignment: start,
  children: [
    if (thinking) AssistantThinkingRow,
    if (content.isNotEmpty) AssistantBubbleCard,
    if (isTerminal) MessageActionRow,
  ],
)
```

### White bubble card

| Spec | Value |
|------|-------|
| Background | `context.scheme.surface` or white — subtle shadow optional |
| Border radius | 16dp |
| Padding | 14–16dp |
| Max width | ~92% screen |
| Border | Optional 1dp `context.appColors.border` |
| Content | `markdown_message_body.dart` |

Do **not** use full-width primary-tinted assistant background — reference is **neutral white card**.

### Thinking row (`assistant_thinking_indicator.dart`)

Shown when `status == thinking | streaming` and content empty or partial.

| Element | Spec |
|---------|------|
| Logo | `AppLogo(size: 28)` or `Image.asset(AppAssets.logoApp)` |
| Dots pill | Grey rounded container (`inputFill`), padding `8×10` |
| Dots | 3 teal circles 8dp, pulsing animation 900ms |
| Label | **Omit** "Thinking…" text in v1 — dots only (matches reference) |

```dart
Row(
  children: [
    AppLogo(size: 28),
    const SizedBox(width: 8),
    Container(
      decoration: BoxDecoration(
        color: context.appColors.inputFill,
        borderRadius: BorderRadius.circular(16),
      ),
      padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 8),
      child: _TealDotsAnimation(),
    ),
  ],
)
```

Reduced motion: static 3 dots + `Semantics(liveRegion: true, label: 'Vithey AI is thinking')`.

**Never show** chain-of-thought, tool JSON, or system prompts.

## User message (`user_message_bubble.dart`)

| Spec | Value |
|------|-------|
| Align | `centerRight` |
| Bubble | Teal `AppColors.primary`, white text, `borderRadius: 18` |
| Max width | 82% |
| Timestamp | Optional muted 11sp below — hide on new minimal design if cluttered |

## Markdown (`markdown_message_body.dart`)

Use `flutter_markdown` — replace any `_RichTextContent` line splitter.

| Feature | Required |
|---------|----------|
| Bold, italic, lists, headings | ✅ |
| Fenced code + Copy | ✅ `code_block_card.dart` |
| Links | ✅ `url_launcher` |
| Tables | ✅ horizontal scroll |

## Message actions (`message_action_row.dart`)

Show when `status` is `complete` or `stopped`.

| Action | Icon | Gate |
|--------|------|------|
| Copy | `Icons.copy` | Always |
| Share | `Icons.share_outlined` | Always (`share_plus`) |
| Regenerate | `Icons.refresh` | Backend / mock flag |
| Timestamp | text | Optional |

Compact ghost icon buttons below white card.

## Status enum

```dart
enum AiMessageStatus {
  sending, thinking, streaming, complete, failed, stopped
}
```

| Status | UI |
|--------|-----|
| `thinking` | Logo + dots row |
| `streaming` | Bubble grows + optional cursor |
| `complete` | Full markdown + actions |
| `stopped` | Partial content + muted "Stopped" |
| `failed` | Error text + Retry |

## Streaming (when enabled — `05`)

- Append deltas to bubble content
- Keep dots row until first delta
- Batch UI updates every 50–100ms

## Security

- Sanitize links — block `javascript:`
- No WebView for assistant HTML
- Finance topic: no fabricated balances
