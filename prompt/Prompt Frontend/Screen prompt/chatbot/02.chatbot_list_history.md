# 02 - Chatbot History Drawer Prompt

Build the conversation-history drawer shown in `Prompt Frontend/screen image/chatbot/chatbot-menu-list-chat-history.png`.

## Layout

- Left drawer covering most, not all, of the screen with dimmed chat behind it.
- Safe-area spacing.
- Full-width teal **New Chat**.
- Divider.
- Optional **Pinned** section.
- **Recent Chats** paginated list.
- Outside tap, swipe left, or Back closes.

## History row

- Title (max two lines/ellipsis).
- Optional preview/updated time.
- Pin indicator.
- Selected session tint.
- Trailing overflow menu; direct trash icon from reference should become safer overflow.
- Menu: Rename, Pin/Unpin, destructive Delete.

Pinned sessions appear once above recent sessions; recent sessions order by `updated_at` descending. De-duplicate by session ID.

## New Chat

- Close drawer and open clean local draft.
- Do not create server session until first message when current API uses `/ai/chat` for creation.
- Preserve unsent current-session draft or confirm before discarding according to policy.

## Rename

- Dialog/sheet titled **Rename chat**.
- Prefilled selected title.
- Cancel / teal Save.
- Trim; reject empty; enforce maximum; preserve Unicode.
- Keep dialog with inline error on failure.
- User rename overrides automatic title generation until reset.

## Pin/Unpin

- Pin moves to Pinned without duplication.
- Unpin returns by `updated_at`.
- Persist server-side across devices.
- Per-row loading, rollback/error, and optional maximum pin limit.

## Delete and confirmation

Always confirm:

- Title: **Delete chat?**
- Message: **This will permanently delete “{title}” and its messages. This action can’t be undone.**
- Neutral Cancel and red Delete.
- Outside tap never confirms.

On confirm, call `DELETE /api/v1/ai/sessions/{id}` for the exact stable ID. Remove only after success or with reliable rollback. If active chat was deleted, open new empty chat. `404` for already-deleted owned session may reconcile as deleted.

## Contract extensions

Current session model needs:

- `title`, `is_pinned`, safe preview.
- Ownership-checked PATCH/update for rename/pin.
- Auto-title/user-override rules.
- Retention/cascade behavior on delete.

Feature-gate Rename/Pin until backend exists; Delete is already supported.

## States/testing

- Drawer initial/pagination skeleton, empty history, footer retry.
- Mutation-specific loading/errors.
- New Chat, rename validation, pin ordering, delete Cancel/success/failure/404/active-session behavior.
- Keyboard/focus trapped in dialogs and restored to originating row.
- Large text/long titles do not overflow.

## Output

Deliver a safe persistent history drawer with New Chat, Rename, Pin, and confirmed per-session Delete.
