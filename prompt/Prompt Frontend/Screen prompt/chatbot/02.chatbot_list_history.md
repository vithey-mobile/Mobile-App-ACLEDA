Build the **simplified history drawer** from `Prompt Frontend/screen image/chatbot/chatbot-menu-list-chat-history.png`.

```
┌──────────────────────────┐

│  Recent Chats            │  muted section header
```

## Drawer shell

| Spec | Value |
|------|-------|
| Widget | `Drawer` via `Scaffold.drawer` |
| Width | `MediaQuery.size.width * 0.82` |
| Surface | White / `context.scheme.surface` |
| Backdrop | Dimmed chat; tap outside closes |
| SafeArea | Top + bottom |

## New Chat button

Match reference — prominent teal block at top.

```dart
Padding(
  padding: const EdgeInsets.all(16),
  child: shad.Button.primary(
    onPressed: () {
      controller.newChat();
      Navigator.pop(context);
    },
    child: Row(
      mainAxisAlignment: MainAxisAlignment.center,
      children: [
        Icon(Icons.add_comment_outlined, size: 20, color: Colors.white),
        SizedBox(width: 8),
        shad.Text('New Chat'),
      ],
    ),
  ),
)
```

- Full width, `borderRadius: 12`
- Closes drawer after tap
- Does **not** create server session until first message sent

## Recent Chats section

| Element | Spec |
|---------|------|
| Header | **Recent Chats** — 13sp, `context.appColors.muted`, padding `16h 8v` |
| Divider | 1dp above header after New Chat button |
| List | `ListView` of session rows |

### Pinned section (feature-gate)

Reference image shows **Recent Chats only**. Implementation options:

| Mode | When |
|------|------|
| **A (match image)** | Single "Recent Chats" list; pin sorts to top silently |
| **B (full)** | Separate "Pinned" header when `isPinned` sessions exist |

**Default: Mode A** for v1 new design — no separate Pinned header.

## History row (`_HistoryTile`)

| Zone | Spec |
|------|------|
| Title | `session.title`, 15sp, max 1 line ellipsis |
| Tap row | `selectSession(id)` + close drawer |
| Trailing | `Icons.delete_outline` 22dp — **trash only** (no `⋮` menu in reference) |
| Selected | Light teal/grey background when `session.id == currentSessionId` |
| Height | Min 52dp |

```dart
ListTile(
  title: Text(session.title),
  trailing: IconButton(
    icon: const Icon(Icons.delete_outline),
    tooltip: 'Delete chat',
    onPressed: () => _confirmDelete(context, session),
  ),
  onTap: () => onSelect(session),
)
```

### Delete flow (required)

1. Tap trash → `shad.AlertDialog`
2. Title: **Delete chat?**
3. Body: *This will permanently delete "{title}" and its messages.*
4. Cancel | **Delete** (`shad.Button.destructive`)
5. `DELETE /ai/sessions/{id}`
6. If active session deleted → `newChat()`

**Do not** delete without confirmation.

### Rename / Pin (secondary — feature-gate)

Not in reference image. Optional via **long-press** context menu:

- Rename → dialog (`PATCH` planned)
- Pin → `togglePin` (`PATCH` planned)

Hide until backend ships; mock may support locally.

## States

| State | UI |
|-------|-----|
| Loading | 3 shimmer rows |
| Empty | "No conversations yet" + subtitle *Start a New Chat* |
| Error | Inline retry + snackbar |
| Pagination | Load more at scroll end — `GET /ai/sessions?page=` |

## API

| Method | Path | Status |
|--------|------|--------|
| GET | `/ai/sessions?page=&limit=` | ✅ |
| DELETE | `/ai/sessions/{id}` | ✅ |
| PATCH | `/ai/sessions/{id}` | planned rename/pin |

### Session JSON

```json
{
  "session_id": "uuid",
  "title": "Study Plan - Arch 201",
  "topic": "STUDENT",
  "is_pinned": false,
  "preview": "Here is a study plan…",
  "updated_at": "2026-07-09T12:00:00Z"
}
```

Auto-title from first user message when backend returns generic title.

## Controller

```dart
Future<void> loadSessions({int page = 1});
Future<void> selectSession(String sessionId);
Future<void> deleteSession(AiSession session);

```
