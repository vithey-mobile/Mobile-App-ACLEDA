# 03 — Chatbot Composer (New Grey Pill Design)

Build the **sticky composer** from `chatbot-home.png` and `Reasoning-bot-response.png`.

## Visual reference

```
┌─────────────────────────────────────────┐
│ ( + ) │ Ask me anything…          ( ➤ ) │
└─────────────────────────────────────────┘
```

Single **light grey pill** spanning screen width (minus horizontal padding).

## Widget: `chatbot_composer.dart`

| Element | Spec |
|---------|------|
| Outer padding | `12h × 8v` from screen edges |
| Container | `borderRadius: 28`, fill `context.appColors.inputFill`, no hard border |
| Min height | ~52dp (one line) |
| Max height | ~6 lines (~160dp) then internal scroll |
| Growth direction | **Upward** — bottom edge pinned above keyboard |

### Inner layout

| Position | Control |
|----------|---------|
| Left | Circular `+` button inside pill — `Icons.add`, 40×40, muted icon |
| Center | Expanded `TextField`, borderless, hint **Ask me anything…** |
| Right | Teal circle send `Icons.send` white icon — or **Stop** when generating |

```dart
Container(
  decoration: BoxDecoration(
    color: context.appColors.inputFill,
    borderRadius: BorderRadius.circular(28),
  ),
  padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 6),
  child: Row(
    crossAxisAlignment: CrossAxisAlignment.end,
    children: [
      _CircleIconButton(icon: Icons.add, onTap: onAttachment),
      Expanded(child: TextField(...)),
      _SendOrStopButton(isGenerating: isGenerating, onSend: onSend, onStop: onStop),
    ],
  ),
)
```

### Send button (idle)

- Teal circle 40×40 (`AppColors.primary`)
- White `Icons.send` / paper plane
- Disabled when text empty or `isGenerating`

### Stop button (generating)

- Same position as send
- `Icons.stop` or square stop icon
- `onStop` → `controller.stopGenerating()`
- Reference shows send during thinking — **prefer Stop** when `isGenerating` (ChatGPT parity)

## Multiline behavior (reference copy)

Assistant message in `Reasoning-bot-response.png` states:

> *"Now the input will stay at the bottom of your mobile screen and grow upward when you add image or multiline text."*

| Rule | Implementation |
|------|----------------|
| `resizeToAvoidBottomInset` | `true` on `Scaffold` |
| `maxLines` | `null` with cap via `minLines: 1, maxLines: 6` |
| Scroll | ListView shrinks when keyboard + tall composer |
| Image attach | Feature-gate — `+` shows "Coming soon" until API supports |

## Send lifecycle

```
1. Trim; validate non-empty
2. Lock send (_sendLocked)
3. Optimistic user bubble
4. Assistant placeholder status: thinking
5. Clear composer + draft
6. Hide suggestion list (hasMessages)
7. scrollToBottom()
8. POST /ai/chat (or stream — 05)
9. thinking → complete / failed / stopped
10. Unlock send
```

## Per-session drafts

| Event | Draft |
|-------|-------|
| Switch session | Save/restore per `sessionId ?? 'draft'` |
| Send success | Clear draft |
| `newChat()` | Clear composer + `'draft'` key |
