### Header

- Centered **fee name** (bold, ~20–22).
- Centered **invoice / transaction reference** under title (muted, slightly tracked / uppercase-friendly).
- Optional drag handle; close control remains accessible (top corner or swipe dismiss).

### Status / date panel

- Full-width rounded panel with **state-tinted fill**:
  - **Paid** → soft teal / mint fill
  - **Pending** (unpaid) → soft peach / warm fill
  - **Overdue** → soft red / warm fill (same pattern as Pending, stronger emphasis)
- Left column:
  - Small muted **STATUS** label
  - Solid pill badge with **white** label text: `PAID` / `PENDING` / `OVERDUE`
    - Paid pill: brand teal
    - Pending pill: orange / warning
    - Overdue pill: error red
- Right column:
  - Small muted **DATE** label (not “Paid Date” / “Due Date” wording — mock uses **DATE**)
  - Formatted date in the **accent color** for that state (paidAt when Paid; dueAt when Pending/Overdue)

### Breakdown

- Section label **BREAKDOWN** (small, bold, muted, letter-spaced).
- Rows (label left, amount right):
  1. Base Amount
  2. Processing Fee
  3. Late Charge (singular copy per mock; map from `lateCharges`)
- Late Charge amount uses accent color (teal when Paid, red/orange when Pending/Overdue).
- Other row amounts use theme heading / body color.

### Total

- Thin divider.
- Left: **Total Due** (mock uses this label for both Paid and Pending — keep consistent unless product later prefers “Total Paid”).
- Right: large bold total in **accent color** (teal Paid, red Pending/Overdue).

### Actions

Two full-width primary (teal) buttons stacked:

1. **Download PDF Invoice** — download icon + label; loading / progress / error as documented.
2. **Report an Issue** — help / question icon + label; open support / report flow when available (placeholder snackbar acceptable until support route exists). Do not invent a backend.

## Color / theme rules

| State | Panel fill | Pill | Date + Late Charge + Total |
| --- | --- | --- | --- |
| Paid | Soft teal | Solid teal, white text | Teal / primary |
| Pending | Soft peach | Solid orange, white text | Orange date; red total & late |
| Overdue | Soft red tint | Solid red, white text | Red accents |

Theme-aware surfaces for the sheet itself (light/dark). Accent colors stay brand-readable on both modes.

## Data / PDF / security / a11y

Same rules:

- Load owned detail via `GET /api/v1/payments/{paymentId}`.
- Authoritative breakdown; minor-unit money; verify `base + processing + late â‰ˆ total`.
- **Finance Home list amount must equal this total** (not base alone).
- Authenticated PDF download; no public permanent URLs; no logging of PII/amounts/refs.
- Focus trap, 44×44 targets, status not by color alone (pill text + labels).
