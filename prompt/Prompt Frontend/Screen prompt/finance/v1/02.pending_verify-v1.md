### Status hero cards (`Verified.png`)

Shared style: linear gradient card, centered translucent circle, **white outline clock**, white title + subtitle.

| Status | Gradient | Title | Subtitle |
| --- | --- | --- | --- |
| Pending | Orange → red-orange | **Verification Pending** (correct spelling) | Your application is under review. |
| Verified | Lime → green | **Verified Success** | Your application has been confirmed. |
| Not submitted | Linear grey | **Not Verified** | You haven't submitted your application yet. |

### Submission → status mapping (document gate)

| Condition | Flow |
| --- | --- |
| Empty / incomplete ID or email | Stay on form (validation). |
| ID + email, **no** document | Submit → **Pending** 3s → **Not Verified** (fail) + **Verify again** |
| ID + email + **document** | Submit → **Pending** 3s → **Verified Success** |

**Verify again** opens the verification form (Screen 1) and prefills prior Student ID / email (and document name when stored).

## Pending state (match Verification Status Screen.png)

### Header

- Title: **Verification Status**
- Subtitle: **Your verification is pending**

### Status hero card

Match **Verified.png** pending variant:

- Full-width rounded card (~22px radius).
- Orange → red-orange **linear** gradient (left → right).
- Centered **translucent** circle with **white outline clock** (not a solid white badge).
- Bold white title: **Verification Pending**
- Supporting white text: **Your application is under review.**

Verified / Not Verified cards use the same icon chrome with green / grey gradients and copy from the table above.

### Progress section

- Section heading: **Verification Status** (not “Verification Timeline”).
- Three vertical steps with connector line between icons:

| Step | Icon treatment | Title | Subtitle |
| --- | --- | --- | --- |
| 1 | Green filled circle + white check | **Application Submitted** | Server `submittedAt` formatted (e.g. `June 1, 2026`) — do not hard-code in production |
| 2 | Orange filled circle + white clock | **Under Review** | **In progressing...** (match mock wording) |
| 3 | Grey filled circle + white info | **Verification Complete** | **Pending** |

- Announce current stage for a11y (**Step 2 of 3** while pending).

### Submitted Documents

- Bordered rounded card.
- Heading: **Submitted Documents**
- Row: ID-card / badge icon · **Student ID Card** · green **Uploaded** (end-aligned).
- Prefer display label **Student ID Card** (not raw file name) unless product asks otherwise.
- Preview rules unchanged from v0 (auth short-lived URL only).

### What happens next?

- Rounded card with **light grey** fill (not teal tint).
- Heading: **What happens next?**
- Two muted paragraphs (prefer correct grammar while matching layout):

  1. **Our verification team is reviewing your documents. This typically takes 24 - 48 hours.**
  2. **You'll receive an email notification once your verification is complete.**

### Actions on pending (v1)

- The new pending mock **does not** show Contact Support on this screen.
- Keep Contact Support available for rejected / support entry points from v0 if already wired elsewhere; do not force a pending CTA that isn’t in the image.
