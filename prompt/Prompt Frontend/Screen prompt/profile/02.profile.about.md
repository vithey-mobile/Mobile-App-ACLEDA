## Goal

Show skills and public (or own) profile details under the Profile shell. Match the About reference: a **vertical stack of titled sections**, not a single collapsed “Personal details” block with expand-only work/education.

### Layout rules

| Spec | Value |
|------|-------|
| Horizontal padding | **20px** (`EdgeInsets.fromLTRB(20, 16, 20, 100)` on About `ListView`) |
| Section gap | ~18–20px between section blocks |
| Section title | Bold 16sp, heading color |
| Row | Leading outline icon (muted, 20dp) + value text (~15sp) |
| Empty section | Hide the section when it has no rows |
| Owner all-empty | `Add your details in Edit Profile Info` |
| Visitor all-empty | `No public information` |

## Detail sections (v1 structure)

Named sections as in the mock (not one expandable personal block). Implemented by `ProfileAboutDetails`:

| Section title | Rows when data exists | Icons (current) |
|---------------|------------------------|-----------------|
| **Personal details** | `location`, DOB (`MMMM dd yyyy`) | `location_on_outlined`, `cake_outlined` |
| **Work** | `workplace` | `apartment_outlined` |
| **Education** | `education[]` schools, then `university` if not already listed, then `major`, then `Class of {graduationYear}` | `school_outlined`, `menu_book_outlined`, `calendar_today_outlined` |
| **Links** | `portfolioUrl` (label = URL), `telegramLink` / `facebookLink` (label = Telegram / Facebook) | `link`, teal tappable text |
| **Contact info** | `phone`, `email` — **own profile only** | `phone_outlined`, `email_outlined` |

## Privacy rules

- Visitor never sees phone/email on profile (not in user-profile-service public v1)
- Owner may see Contact info when available from auth/settings/mock
- Owner edits via **Edit Profile Info** → `07.profile_edit_info.md`
- Never render bio/links as HTML
- Validate `https://` before launch; snackbar (or confirm dialog if already used) for bad/external link failures

## API

| Viewer | Endpoint |
|--------|----------|
| Own | `GET /api/v1/users/me` |
| Visitor | `GET /api/v1/users/{userId}` |
| Update | `PATCH /api/v1/users/me` (owner only, via Edit screen) |

See `Prompt Backend/services/user-profile-service/`.
