# 07 — Edit Personal Info — as built

Build / maintain **Edit personal info** from implemented code on `ayheng`.

- Visual: `Profile (Edit info).png` / `Profile (Edit info) 2.png`
- Sheet chrome: `Edited Content.png`
- Full as-built rules: root [`update.md`](update.md)

> Do not regress to older “Add on every section + editable %” behavior.

## Route

| Field | Value |
|-------|-------|
| Route | `AppRoutes.editProfile` |
| Module | `edit_profile_screen.dart`, `profile_section_sheets.dart`, `edit_profile_bottom_sheet.dart` |
| Auth | Own profile only |
| Entry | Profile → **Edit Profile Info** |

## Goal

Owner maintains profile sections via bottom sheets. Skills persist immediately; other sections persist on footer **Save**. About must match after save / skill persist.

## Layout

`
┌─────────────────────────────────────┐
│ ←  Edit personal info               │
├─────────────────────────────────────┤
│ Skills                              │  ⊕ Add Skill + rings (no header Add)
│ Bio                                 │  Title only — no Add, no icon
│ Personal details               Add  │
│ Work                           Add  │
│ Education                      Add  │
│ Links                          Add  │
│ Contact info                   Add  │
├─────────────────────────────────────┤
│ [ Save ]              [ Cancel ]    │
└─────────────────────────────────────┘
`

| Spec | Value |
|------|-------|
| Content padding | `fromLTRB(20, 8, 20, 24)` |
| Footer | Save (primary) + Cancel; `fromLTRB(20, 12, 20, 12)` |

## Interaction

| Action | Result |
|--------|--------|
| ⊕ Add Skill / tap ring | Skill sheet (add or edit) |
| Skill submit / remove | Apply to list + **`persistSkills()` immediately** |
| Bio tap | Bio sheet (no leading icon on list row) |
| Section **Add** / tap row | Create / edit sheet for that section |
| Sheet **Remove** (edit only) | Confirm → delete/clear that item |
| Footer **Save** | Persist full draft; `Get.back(true)`; Profile refreshes |
| Footer **Cancel** | Pop without full save (skills already persisted stay) |

Sheet result type: `ProfileSheetResult.saved(T)` / `.deleted()`.

## Bottom sheet chrome

| Spec | Value |
|------|-------|
| Presentation | Modal bottom sheet, full width, drag handle |
| Padding | Horizontal **20px** |
| Title | Add/Edit {section}; **Remove** trailing when editing existing |
| Actions | Submit + Cancel |

## Skills sheet (as built)

### Selection

1. L1: top-level catalog (`startupSkills` + Other).
2. If **Coding** → L2 Frontend / Backend / Other.
3. Frontend/Backend → L3 tech list (≥20) + Other last.
4. Other → custom name + optional Choose icon / Choose image.

### Fields

| Field | Behavior |
|-------|----------|
| Skill* | Picker row (shows icon + name when set) |
| Skill name | When Other |
| Skill icon (optional) | Choose icon \| Choose image \| Remove |
| Color | Palette + custom HSV |
| Skill level | **Display only** — ring + disabled slider; helper “Set automatically by the system”; **no** 25/50/75/100 chips |
| New skill % | **0** |
| Existing % | From profile; not user-editable |

### Persist

`EditProfileController.persistSkills()` → `ProfileRepository.updateProfile(skills: …)` → sync own `ProfileController.profile`.

## Bio

- No Add button; no quote icon on the row.
- Multiline sheet; Remove clears bio (footer Save persists).
