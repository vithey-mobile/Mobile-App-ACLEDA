# 07 — Edit Personal Info — v1

Build the **Edit personal info** screen from:

- `Profile (Edit info) 2.png` — section layout (Skills + titled sections)
- `Edited Content.png` — **Add / Edit bottom sheet** (Work example)
- Interaction rules in root `update.md` (**do not modify** `update.md` while implementing)

> This file is the complete v1 prompt. Original: `v0/07.profile_edit_info.md`.

## Route

| Field | Value |
|-------|-------|
| Route | `AppRoutes.editProfile` |
| Module | `lib/modules/profile/edit_profile_screen.dart` (+ bottom-sheet widgets) |
| Auth | Own profile only |
| Entry | Profile → **Edit Profile Info** |
| Prompt | `Screen prompt/profile/v1/07.profile_edit_info-v1.md` |

On **Save** (footer), persist draft and `Get.back(result: true)` so Profile soft-refreshes About + header.

## Goal

Let the owner maintain profile sections via **per-item Add / Edit bottom sheets**, then save the whole draft. About tab must show the same data after save.

## Layout (screen)

```
┌─────────────────────────────────────┐
│ ←  Edit personal info               │
├─────────────────────────────────────┤
│ Skills                         Add  │  Rings; tap ring → edit skill
│ Bio                            Add  │  Tap bio → edit
│ Personal details               Add  │  Tap row → edit personal
│ Work                           Add  │  Tap job → edit work
│ Education                      Add  │
│ Links                          Add  │
│ Contact info                   Add  │
├─────────────────────────────────────┤
│ [ Save ]              [ Cancel ]    │  Footer; 20px pad
└─────────────────────────────────────┘
```

- Horizontal content padding **20px**
- Light / dark via `appColors` + `colorScheme`
- Section title ~18sp bold; header action is **Add** (not Edit)

## Interaction model

| Action | Result |
|--------|--------|
| Tap **Add** in section header | Bottom sheet — empty fields — **create** item |
| Tap existing content item | Bottom sheet — prefilled — **update that item only** |
| Submit in sheet | Apply to local draft; close sheet; other items unchanged |
| Cancel in sheet | Discard sheet edits; close |
| Footer **Save** | Persist full draft via repository; pop `true` |
| Footer **Cancel** | Pop without saving |

Only **one** bottom sheet open at a time.

## Bottom sheet (`Edited Content.png`)

| Spec | Value |

Work reference fields:

1. **Position**
2. **Workplace\*** (required)

Other sections use their field sets below (same chrome).

## Section field sets

### Skills
- Skill name
- Skill percentage (0–100)
- List UI: skill rings; tap ring → edit that skill

### Bio
- Bio (multiline)
- At most one bio string; Add if empty, else tap to edit

### Personal details
- Location
- Gender
- Date of birth (real `showDatePicker`)
- Display as tappable rows on the screen; Add/Edit opens sheet with all three fields

### Work
- Position
- Workplace\* (required)
- Description (optional)
- List items: show position + workplace (e.g. `Web Developer · Fintech Center`)

### Education
- School / University
- Major
- Certificate
- Description (optional)

### Links
- Platform name (e.g. Facebook)
- URL

### Contact info
- Phone number
- Email address
- List items may be phone-only, email-only, or both

## Data model (mock-friendly)

Prefer structured lists on `UserProfileModel` (mock store):

| Type | Fields |
|------|--------|
| `ProfileSkill` | `name`, `proficiency` |
| `ProfileWorkEntry` | `position`, `workplace`, `description?` |
| `ProfileEducationEntry` | `school`, `major?`, `certificate?`, `description?` |
| `ProfileLinkEntry` | `platform`, `url` |
| `ProfileContactEntry` | `phone?`, `email?` |
| Personal | `location?`, `gender?`, `dateOfBirth?` |
| Bio | `bio?` |

Legacy string fields (`workplace`, `education[]`, telegram/facebook URLs) may seed the structured lists on load; About reads structured data first.

## About sync

After footer Save + Profile `refreshProfile()`:

- About shows **Bio** section when bio non-empty
- Work / Education / Links / Contact / Personal / Skills match edit draft
- Header bio under avatar also updates from `profile.bio`

## States

| State | Behavior |
|-------|----------|
| Loading | Center progress |
| Empty section | Title + Add only |
| Sheet validation | Block Submit if required empty (e.g. Workplace) |
| Saving | Disable footer Save; show progress |
