## Goal

Show the user's POSTER posts as a vertical feed reusing the Home poster card language, with **20px** horizontal screen padding to match profile home / About / Videos v1.

## Layout

```
┌─────────────────────────────────────┐  ← 20px screen padding
│ (av) Display name                   │
│      Public · 20m ago          ⋮    │
│                                     │
│ HTML is the standard markup...      │
│ ┌─────────────────────────────────┐ │
│ │        [poster image]           │ │
│ └─────────────────────────────────┘ │
│ ♡ Like   💬 Comment   ↗ Share       │  FeedActionBar alignStart (same as Videos)
└─────────────────────────────────────┘
```

## Card

Reuse `PosterPostCard` / `PostCard` — do not duplicate card layout.

| Spec | Value |
|------|-------|
| Screen padding | List **20px** horizontal; card horizontal margin **0** inside that list (so edge-to-card = 20) |
| Vertical gap | Existing card vertical margin (~6–8dp) |
| Actions | Shared `FeedActionBar` with `alignStart: true` — same as Profile Videos |
| Type filter | Only `PostType.poster` |

## Data

- `GET /api/v1/users/{userId}/posts?type=POSTER&page=&limit=`
- Reuse Home poster card contract

## Behavior

| Action | Result |
|--------|--------|
| Tap card / image | `PostDetail(postId)` |
| Like / Comment / Share | Shared media prompts / existing handlers |
| Pull to refresh | Reload page 1 |
| Scroll end | Paginate |

## Owner vs visitor

| Rule | Detail |
|------|--------|
| Own posts | No self-Follow on card; optional ⋮ menu (Edit/Delete) when API exists |
| Visitor | Standard engagement actions |
| Visibility | Server filters private/draft posts |

## States

| State | Copy |
|-------|------|
| Loading | Skeleton / loading widget |
| Owner empty | **Create your first poster** + CTA to Create Post |
| Visitor empty | **No posters yet** |
| Error | Footer Retry |
