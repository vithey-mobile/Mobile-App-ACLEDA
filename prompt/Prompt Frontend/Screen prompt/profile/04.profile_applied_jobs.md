# 04 — Profile Applied Jobs Tab

Build the **Applied Jobs** tab from `Own Profile (Applied Job).png`.

> **Own profile only.** Hide this tab for visitor profiles — see `01.profile_home.md`.

## Layout — empty state (reference)

```
┌─────────────────────────────────────┐
│                                     │
│         [sad document icon]         │
│                                     │
│      No apply job history           │
│  You don't have any apply job       │
│  history.                           │
│                                     │
└─────────────────────────────────────┘
```

## Layout — with data

Compact list cards (similar to Jobs tab but applicant perspective):

| Field | Spec |
|-------|------|
| Job title | Bold |
| Company | Muted |
| Applied date | `Applied 3 days ago` |
| Status pill | Pending / Under review / Accepted / Rejected |
| Tap | My application detail (when route exists) or job post detail |

## Data

- `GET /api/v1/users/me/job-applications?page=&limit=`
- Or `GET /api/v1/job-applications?applicant_id=me`

```json
{
  "id": "app-uuid",
  "job_post_id": "uuid",
  "job_title": "Web Developer",
  "company": "Aeon Mall",
  "status": "PENDING",
  "applied_at": "2026-07-07T10:00:00Z"
}
```

## Status pill colors

| Status | Color |
|--------|-------|
| Pending | Amber |
| Under review | Blue |
| Accepted | Green |
| Rejected | Red/grey |

## States

| State | UI |
|-------|-----|
| Loading | 3 skeleton rows |
| Empty | Match reference illustration + copy exactly |
| Error | Inline Retry |

Use `EmptyStateWidget` with custom illustration asset when available.

## Widget

```text
lib/modules/profile/widgets/

  profile_applied_job_card.dart
  profile_applied_jobs_empty.dart
```

## Controller

- Lazy-load when Applied Jobs tab first selected
- Only register 5th tab in `TabController` when `isOwnProfile`

## Acceptance criteria

- [ ] Tab hidden on visitor profiles
- [ ] Empty state matches `Own Profile (Applied Job).png`
- [ ] Populated list shows status pills
- [ ] Pull to refresh + pagination
- [ ] Tap opens correct job/application destination
