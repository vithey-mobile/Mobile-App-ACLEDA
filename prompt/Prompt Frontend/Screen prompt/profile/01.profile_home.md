# 01 — Profile Home Shell (Owner / Visitor)

Build the shared **Profile shell** from:

- `Own Profile (About).png` — authenticated user
- `View Profile (About).png` — another user's profile

## Route

| Field | Value |
|-------|-------|
| Route | `AppRoutes.profile` with `ProfileArgs(userId)` |
| Module | `lib/modules/profile/` |
| Entry | Bottom nav Profile tab, avatar taps, notifications |

Compute `isOwnProfile = targetUserId == authSession.userId`. Never trust a caller-supplied owner flag.

## Wavy cover header (`profile_wavy_header.dart`)

| Spec | Value |
|------|-------|
| Height | ~160–180dp |
| Background | `AppColors.primary` gradient or solid teal |
| Bottom edge | Wavy / organic curve via `ClipPath` or SVG |
| Decor icons | Faded white line-art: `</>`, star, dice, 3D cube, chat bubble — decorative only |
| Menu | Hamburger `Icons.menu` top-left (own profile → drawer/settings) |

Do not use a flat rectangular banner — match the curved transition in reference images.

## Avatar (`profile_avatar.dart`)

| Spec | Value |
|------|-------|
| Size | 96–104dp diameter |
| Position | Centered, overlapping cover bottom by ~50% |
| Border | 3–4dp white ring + thin dark outline |
| Source | `avatarUrl` or initials fallback via `UserAvatar` |

## Stats row (`profile_stats_row.dart`)

Three equal columns — reference shows **Likes**, not post count:

| Column | Field | Format |
|--------|-------|--------|
| Likes | `totalLikes` or aggregated reaction count | `128K`, `10K` |
| Followers | `followerCount` | `40K`, `8K` |
| Following | `followingCount` | `3.8K`, `1K` |

- Number: bold 16–18sp
- Label: muted 12sp below number
- Tap optional → future followers/following list (feature-gate)

## Bio

- Centered, max 2 lines collapsed, expandable on tap if longer
- Muted grey `context.appColors.muted`
- Never render as HTML

## Action row (`profile_action_row.dart`)

### Own profile (`isOwnProfile == true`)

| Button | Style | Action |
|--------|-------|--------|
| **Edit profile info** | Primary teal fill, white text, pencil icon | `AppRoutes.editProfile` → `05.profile_edit_info.md` |
| **Verify student** | Outlined white/grey border | `AppRoutes.verification` when not verified; hidden or "Verified ✓" when done |
| **Share** | Icon-only teal outline square | Native share sheet with profile link |

Never show **Follow** or **Message** on own profile.

### Visitor profile

| Button | Style | Action |
|--------|-------|--------|
| **Follow** / **Following** | Primary teal when not following; outlined when following | `toggleFollow()` optimistic |
| **Message** | Outlined | `startMessage()` → chat or request composer |
| **Share** | Icon-only | Share profile link |

## Bottom navigation

- Reuse `HomeBottomNavigation` with `currentIndex: 4` (Profile active)
- Center FAB (+) for Create Post
- Profile tab: teal icon + light teal pill background

## Follow behavior

- Optimistic POST follow / DELETE unfollow
- Rollback on failure
- Sync count across Home and Profile caches
- Server rejects self-follow; UI never shows it

## Message behavior

- Existing ACTIVE conversation → `ChatDetail`
- PENDING request → request state UI
- No conversation → explicit composer → `POST /conversations/request`
- Never auto-send default first message

## API contract (aggregate profile)

> Full spec: [`06.profile_api_backend.md`](06.profile_api_backend.md)

**Profile header** — `GET /api/v1/users/me` (own) or `GET /api/v1/users/{userId}` (visitor):

```json
{
  "user_id": "uuid",
  "full_name": "Khorn Molika",
  "bio": "...",
  "avatar_url": "..."
}
```

**Stats row** — from **content-service** (not profile PATCH): likes, followers, following counts via separate calls or enriched DTO when content API provides it.

**Avatar update** — `POST /files/upload` (AVATAR) + `PATCH /users/me/avatar` (own only).

Do not expect `cover_url`, `stats`, or `is_following` on user-profile-service responses today.

## States

| State | UI |
|-------|-----|
| Loading | Header skeleton + tab skeleton |
| Error | `AppErrorWidget` with Retry |
| Blocked/private | Safe message; no leaked fields |
| Logout | Clear user-scoped caches |

## Accessibility

- Label avatar, stats, action buttons, tabs
- Min tap target `44×44`
- Do not use color alone for Follow/Following state
- Support 320px width and large text

- [ ] Avatar overlaps cover correctly
- [ ] Likes / Followers / Following stats with K formatting
