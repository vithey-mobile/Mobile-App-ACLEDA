# 03 — Applicant Detail — Job List Detail

Build the applicant **detail / CV summary** screen from `Job List Detail.png`.

## Route

| Field | Value |
|-------|-------|
| Route | `AppRoutes.applicantDetail` |
| Args | `ApplicantDetailArgs(applicationId, jobPostId)` |
| Entry | **Details** on Application list card |

## Header

| Element | Spec |
|---------|------|
| Cover | Smaller teal banner with decor icons — same family as profile cover |
| Avatar | Circular, overlaps cover bottom-left |
| Name | Bold |
| **View Profile** | Teal button → visitor profile `ProfileArgs(userId)` |
| Applied role | `Apply position: {job title}` muted |
| Contact | Location + email rows |

## Experience timeline (`experience_timeline.dart`)

| Element | Spec |
|---------|------|
| Vertical line | Grey 2dp left rail |
| Node | Teal filled circle per entry |
| Title | Bold |
| Company | Muted |
| Date badge | Right-aligned teal pill — `2021 - Present` |
| Description | Grey body text, expandable if long |

Repeat pattern for **Education** section with graduation cap icon nodes.

## Owner actions (sticky bottom)

| Button | Action |
|--------|--------|
| Accept | Same as list — confirm → success screen |
| Reject | Confirm dialog |
| View CV | `04.preview_cv.md` — secure PDF viewer |

## API

`GET /api/v1/job-applications/{applicationId}`

Includes applicant profile summary, experience[], education[], cv_file_id (not public URL).

## Privacy

- Hiring-purpose data only
- Log access without PII in production logs
- CV via short-lived signed URL from file-service

## States

| State | UI |
|-------|-----|
| Loading | Header + timeline skeleton |
| Error | Retry |
| CV unavailable | Disabled View CV + message |
