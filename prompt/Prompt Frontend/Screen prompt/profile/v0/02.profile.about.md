## Skills section (`profile_skills_row.dart`)

| Spec | Value |
|------|-------|
| Heading | **Skills** — bold 16sp |
| Layout | Horizontal `ListView` — scrollable |
| Item | Circular progress ring 64–72dp |
| Center text | Percentage e.g. `75%` |
| Label below | Skill name e.g. `Flutter` |
| Colors | Per-skill accent (teal, orange, green, purple) — from server or palette rotation |

```dart
class ProfileSkill {
  final String name;
  final int proficiency; // 0–100
  final Color? accentColor;
}
```

Owner may tap a skill → edit flow in `07.profile_edit_info.md`.
Visitor: read-only rings.

Empty: hide section or show "No skills added yet" (owner only).

## Privacy rules

- Visitor never sees phone/email on profile (not in user-profile-service v1)
- Owner sees all own v1 fields; edit via **Edit profile info** → `07.profile_edit_info.md`
- Never render bio/links as HTML
- Validate `https://` before launch; confirm dialog for external links

## API

| Viewer | Endpoint |
|--------|----------|
| Own | `GET /api/v1/users/me` |
| Visitor | `GET /api/v1/users/{userId}` |
| Update | `PATCH /api/v1/users/me` (owner only, via Edit screen) |

See [`08.profile_api_backend.md`](08.profile_api_backend.md).
