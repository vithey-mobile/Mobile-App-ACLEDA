# 03 — Profile Posters Tab

Build the **Posters** tab from `Own Profile (Posters).png`.

## Layout

Vertical feed of poster cards — same visual language as Home feed:

```
┌─────────────────────────────────────┐
│ (av) Khorn Molika                   │
│      Public · 20m ago          ⋮    │
│                                     │
│ HTML is the standard markup...      │
│ ┌─────────────────────────────────┐ │
│ │        [poster image]           │ │
│ └─────────────────────────────────┘ │
│ ♡ 12   💬 3   ↗ Share              │
└─────────────────────────────────────┘
```

## Data

- `GET /api/v1/users/{userId}/posts?type=POSTER&page=&limit=`
- Reuse `PosterPostCard` from `../media/card_poster/01.poster_sample.md`

## Behavior

| Action | Result |
|--------|--------|
| Tap card / image | `PostDetail(postId)` |
| Like / Comment / Share | Shared media prompts |
| Pull to refresh | Reload page 1 |
| Scroll end | Paginate |

## Owner vs visitor

| Rule | Detail |
|------|--------|
| Own posts | No self-Follow on card; optional ⋮ menu (Edit/Delete) when API exists |
| Visitor | Standard engagement actions |
| Visibility | Server filters private/draft posts |

## States

| State | Copy |
|-------|------|
| Loading | 3 skeleton cards |
| Owner empty | **Create your first poster** + CTA to Create Post |
| Visitor empty | **No posters yet** |
| Error | Footer Retry |
