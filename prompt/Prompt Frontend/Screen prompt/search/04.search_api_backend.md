# 04 — Search REST API & Backend Contract

Backend-ready contract for global search across **user-profile-service** and **content-service**.

**Backend implementation spec (read first):** `Prompt Backend/_shared/SEARCH.md`

## Endpoints

Base: Flutter `api_endpoints.dart` paths **omit** `/api/v1`.

### People search (implemented)

| Method | Path | Service |
|--------|------|---------|
| GET | `/users/search?search={q}&page=&limit=` | user-profile-service |

```json
{
  "data": [
    {
      "user_id": "uuid",
      "full_name": "Heng Liza",
      "avatar_url": "https://...",
      "university": "AUB",
      "major": "Graphic Design",
      "headline": "Graphic designer"
    }
  ],
  "meta": { "page": 1, "limit": 20, "total": 3 }
}
```

### Content search (required extension)

| Method | Path | Service |
|--------|------|---------|
| GET | `/posts?search={q}&type=&page=&limit=` | content-service |

| `type` | Results |
|--------|---------|
| omitted / `ALL` | Posters + videos + jobs mixed |
| `POSTER` | Posters only |
| `VIDEO` | Videos only |
| `JOB` | Job posts only |

```json
{
  "data": [
    {
      "id": "post-uuid",
      "type": "JOB",
      "content": "Multiple position at Aeon Mall",
      "author": { "id": "...", "full_name": "..." },
      "media_url": "...",
      "thumbnail_url": "...",
      "job_meta": { "title": "...", "company": "..." },
      "created_at": "2026-07-09T10:00:00Z"
    }
  ],
  "meta": { "page": 1, "limit": 10, "total": 42 }
}
```

Backend: PostgreSQL `ILIKE` or trigram/GIN full-text on `content`, `job_meta.title`, `profiles.full_name` join for author display.

### Presence (optional)

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/users/{id}/presence` | `online`, `last_seen_at` for Recent subtitle |

## Error mapping

| HTTP | Code | Flutter |
|------|------|---------|
| 400 | `VALIDATION_ERROR` | Query too short snackbar |
| 401 | `UNAUTHORIZED` | Refresh token / login |
| 429 | `RATE_LIMITED` | Backoff + "Try again" |
| 5xx | — | Retry banner |

## Security

- Search returns only **authorized visible** profiles/posts
- No private/draft posts in results
- Rate-limit per user on gateway
- Log queries without PII in production
