# 02 — Search Results (Grouped Facebook Style)

Build **live search results** while the user types — Facebook/Meta grouped sections.

## When to show

| Condition | View |
|-----------|------|
| `query.trim().isEmpty` | Recent (`01`) |
| `query.trim().length == 1` | Recent + inline hint *Type at least 2 characters* |
| `query.trim().length >= 2` | Grouped results (this prompt) |

Debounce: **350ms** after last keystroke before API calls.

## Section header (`search_section_header.dart`)

| Element | Spec |
|---------|------|
| Title | **People** / **Posts** / **Jobs** / **Videos** — bold 16sp |
| Trailing | **See all** when `total > previewLimit` (default preview 3) |
| Tap See all | Push `SearchSeeAllArgs(category, query)` or expand inline |

## People row (`search_person_tile.dart`)

| Element | Spec |
|---------|------|
| Avatar | 48dp |
| Title | `fullName` bold |
| Subtitle | `headline` or `major · university` muted |
| Trailing | Optional `Message` icon — start chat |
| Tap row | `ProfileArgs(userId)` + save to recents |

## Post row (`search_post_tile.dart`)

Compact card for `POSTER` type:

| Element | Spec |
|---------|------|
| Thumbnail | 56×56 left, rounded 8dp |
| Title | First line of content, 2 lines max |
| Meta | Author name · relative time |
| Tap | `PostDetail(postId)` |

## Job row (`search_job_tile.dart`)

| Element | Spec |
|---------|------|
| Icon/thumb | Briefcase or job image 56dp |
| Title | Job title bold |
| Subtitle | Company · location |
| Tap | `PostDetail` or Apply flow if eligible |

## Video row (`search_video_tile.dart`)

| Element | Spec |
|---------|------|
| Thumbnail | 16:9 small with play overlay |
| Title | Caption / title 1 line |
| Tap | `PostDetail` with video |

## Loading & empty

| State | UI |
|-------|-----|
| Searching | Section skeletons (2 rows each) |
| No results | Centered **No results for "{query}"** |
| Partial | Show only non-empty sections |
| Error | Inline retry banner; keep field editable |

## Controller additions

```dart
final people = <UserSearchResult>[].obs;
final posts = <PostSearchResult>[].obs;
final jobs = <PostSearchResult>[].obs;
final videos = <PostSearchResult>[].obs;
final isSearching = false.obs;
final searchError = RxnString();

Future<void> runSearch(String query);
void openPerson(UserSearchResult user);
void openPost(PostSearchResult post);
void messagePerson(UserSearchResult user); // → chat
```

Parallel fetch:

```dart
await Future.wait([
  _searchRepository.searchUsers(q),
  _searchRepository.searchPosts(q, type: null),
  _searchRepository.searchPosts(q, type: PostType.job),
  _searchRepository.searchPosts(q, type: PostType.video),
]);
```

Cancel stale responses when query changes (track `searchGeneration` int).

## Highlight matching text (optional v1)

Bold the substring match in names/titles — Facebook blue not required; semibold match segment is enough.

## Mock mode (`USE_MOCK_API=true`)

Filter seeded users/posts from `ProfileRepository` / `PostRepository` by case-insensitive `contains` on name, content, job title.
