## Data model

```dart
enum ApplicationPhase { submitted, underPreview, decision }

enum ApplicationDecision { pending, accepted, rejected }

class ApplicationTimelineStep {
  final ApplicationPhase phase;
  final String label;           // Submitted | Under Preview | Decision
  final DateTime? completedAt;
  final String? statusText;     // Pending, or timestamp line
  final bool isComplete;
  final bool isCurrent;
  final bool isRejectedDecision; // red flag on Decision node
}

class ApplicationStatusViewModel {
  final String applicationId;
  final String jobTitle;
  final String? organization;
  final ApplicationDecision decision;
  final List<ApplicationTimelineStep> timeline;
  final String? bannerMessage;
  final String? employerMessage; // reviewer note — quoted card
}
```

Map from `GET /api/v1/job-applications/{applicationId}` or list item detail endpoint.

### Status → UI mapping

| API `status` | Hero | Timeline |
|--------------|------|----------|
| `PENDING` (just created) | Paper plane — **Application Submitted!** | Step 1 ✓ teal; 2–3 ○ gray, **Pending** |
| `REVIEWED` / in review | People icon — **Under Review** | Steps 1–2 ✓; step 3 ○ **Pending** |
| `ACCEPTED` | Check in teal card — **Accepted** | All 3 ✓; Decision has flag/check + timestamp |
| `REJECTED` | Red ✕ — **Not Selected** | Steps 1–2 ✓; Decision red flag + timestamp |

Use backend enum names when they differ; document mapping in repository.

## Timeline (`application_timeline.dart`)

Vertical stepper — left rail + right content.

| Node state | Visual |
|------------|--------|
| Complete | Filled teal circle + white checkmark |
| Pending future | Empty circle, gray `2dp` border |
| Decision accepted | Teal circle + white flag icon |
| Decision rejected | Light red circle + red flag icon |

Connector: `2dp` vertical gray line between node centers.

### Row content

| Field | Format |
|-------|--------|
| Label | Bold — **Submitted**, **Under Preview**, **Decision** |
| Detail | Timestamp `MMMM dd yyyy · h:mm a` when complete; else **Pending** muted |

Example timestamps from references:

- Submitted: `July 07 2026 · 09:14 AM`
- Under Preview: `July 08 2026 · 8:10 AM`
- Decision: `July 08 2026 · 2:35 PM`

Use `intl` with device locale.

| Accepted | *(optional — or omit when employer message shown)* |
| Rejected | *(optional)* |

## Employer message card (accepted / rejected)

Separate white card below main content — `status_message_card.dart`:

| Element | Spec |
|---------|------|
| Icon | Teal person outline |
| Text | Quoted reviewer message in italics |

Examples from references:

- Accepted: *"Thank you for your interest. Please check your email to receive interview time and location."*
- Rejected: *"Thank you for your interest. I'm so sorry to inform you didn't pass our selection. However, we openly welcome you again next time."*

Show only when `employerMessage` / `reviewer_note` is non-empty in API.

## Privacy

- Applicant sees only their own application.
- Employer message is hiring-purpose data — do not log in analytics.
- No public CV URLs in this screen.

## Controller

`ApplicationStatusController`:

- `loadStatus(applicationId)`
- `refresh()`
- `mapToViewModel(JobApplicationModel)`

Subscribe to push notification for this `applicationId` to auto-refresh when status changes (optional; integrate with notification module).
