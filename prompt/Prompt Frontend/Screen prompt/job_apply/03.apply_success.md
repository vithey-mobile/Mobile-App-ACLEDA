# 03 — Application Submitted (Success)

Build the post-submit confirmation from `Prompt Frontend/screen image/job_apply/Apply CV Screen 02.png`.

## Quick info

| Field | Value |
|-------|-------|
| Screen ID | `12B` |
| Route | `Routes.APPLY_SUCCESS` |
| Module | `lib/modules/apply_cv/apply_success_screen.dart` |
| Auth | Required |
| Args | `ApplySuccessArgs(applicationId, jobPostId, jobTitle)` |

## Goal

Confirm successful submission, set expectations, and offer a clear path to track application status. Update originating job cards to **Applied**.

## Copy

| Element | Text |
|---------|------|
| Headline | **Application Submitted!** |
| Body | Your application has been submitted successfully. It will be reviewed soon. Please stay tuned for updates. |

Substitute `{jobTitle}` in body when helpful:

> Your application for **Web Developer** has been submitted successfully…

## Primary CTA — View Application Status

Outline / ghost button (not filled):

| Property | Value |
|----------|-------|
| Border | `1dp` teal |
| Background | transparent / surface |
| Icon | Teal eye outline left of label |
| Label | **View Application Status** |
| Tap | `Get.offNamed(Routes.APPLICATION_STATUS, arguments: ApplicationStatusArgs(applicationId))` |

Use `Get.offNamed` or `Get.offAllNamed` depending on back-stack policy — user should not return to step 2 and resubmit.

## Secondary exit (implicit)

- System back / gesture: return to **origin** (Home / Post Detail), not wizard
- On first paint, emit `ApplyCvResult` so origin updates card:

```dart
ApplyCvResult(
  jobPostId: args.jobPostId,
  applicationId: args.applicationId,
  status: JobApplicationStatus.pending,
)
```

If using `Get.off` chain, pass result via `Get.back(result:)` before replacing route, or use shared `JobApplicationRepository` cache.

## App bar

Reference has **no** app bar — full-bleed centered content.

- Hide back button OR show minimal close (×) top-right that same as system back behavior
- Do not show stepper on success screen

## Accessibility

- Announce: "Application submitted successfully"
- CTA semantics: "View application status for {job title}"
- Illustration marked decorative (`ExcludeSemantics`)

## States

This screen appears only after `201 Created` from `POST /job-applications`.

If opened with invalid/missing `applicationId`, redirect to Home with snackbar.

## Navigation

| From | Action | To |
|------|--------|-----|
| Step 2 Submit success | Auto navigate | `APPLY_SUCCESS` |
| View Application Status | Tap | `APPLICATION_STATUS` |
| Back / close | | Origin feed (card = Applied) |
