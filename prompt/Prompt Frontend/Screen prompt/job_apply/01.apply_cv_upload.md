## Goal

Let an eligible applicant attach a CV (or select saved CV) for a specific job, optionally choose among multiple positions on the same post, and advance to the Review step.

## Header & stepper (`apply_job_stepper.dart`)

| Element | Spec |
|---------|------|
| App bar | Back arrow left; centered title **Apply Job**; bold |
| Stepper | 3 nodes connected by horizontal lines |
| Step 1 active | First node + segment to node 2 = **teal** (`context.appColors.primary`) |
| Future steps | Nodes 2–3 and remaining segment = light gray border |
| Semantics | `Step 1 of 3: Upload CV` |

Back from step 1 returns to origin (Home card / Post Detail / Profile) and discards local file selection after confirm-if-needed.

## Job context (compact, above or inside scroll)

While loading job by `jobPostId`:

- Show compact skeleton for title/organization.
- On error: `AppErrorWidget` + Retry; **Continue** disabled.

When loaded, show read-only context (do not replace the **Upload your CV** heading):

- **Applying for {job title}** — from structured `jobMeta.title`
- Organization / author name
- Optional deadline badge when `jobMeta.deadline` exists

Never apply to an unidentified job.

## Position selector (`position_selector.dart`)

Reference shows a **Position** dropdown defaulting to **Web Developer**.

| Case | UI |
|------|-----|
| Single position on post | Hide dropdown; bind implicit `positionId` / title from `jobMeta` |
| Multiple positions (`jobMeta.positions[]`) | Show `DropdownButtonFormField` or Shadcn select |
| No positions in contract | Omit selector; use job title only |

Rules:

- Required when multiple positions exist.
- Changing position after file pick preserves the selected file.
- Label: **Position**; placeholder: **Select a position**

## CV upload zone (`cv_upload_zone.dart`)

Match dashed rounded rectangle from reference:

| Element | Spec |
|---------|------|
| Container | Large, `16dp` radius, `2dp` dashed border — `context.appColors.border` |
| Icon | Centered stack: gray document illustration + teal/green circle with **+** |
| Primary copy | **Drag & drop your file here** (bold on pointer/desktop) |
| Secondary copy | **or tap to browse** |
| Divider | Thin horizontal rule inside zone |
| Policy line | Dynamic from config — e.g. **PDF, DOC or DOCX (max. 10 MB)** |
| Tap target | Entire zone ≥ `48×48`; keyboard activatable |
| Picker | `file_picker` — no broad storage permission when scoped picker works |

**Policy note:** Reference image says **JPG, PNG, or PDF (Max 5MB)**. Display only what backend `CV` MIME whitelist allows. Current contract: PDF, DOC, DOCX — do not offer JPG/PNG until file-service extends whitelist.

### Saved CV shortcut

If `GET /users/me/cv` returns metadata, show compact row below zone:

- **Use my saved CV** — selects saved file without re-upload
- **Upload a different file** — opens picker (application-only by default)

Do not silently overwrite saved CV. See [`05.apply_cv_api.md`](05.apply_cv_api.md).

### After file selected

Replace or overlay zone with `selected_cv_card.dart` (compact variant):

- PDF/DOC icon by MIME
- Safe filename (ellipsis) + formatted size
- **Replace** / **Remove**
- Validation error text directly below

## Continue button

| State | Behavior |
|-------|----------|
| Disabled | Job not loaded/eligible; no valid CV; position required but empty; validation running |
| Enabled | Valid CV (local or saved) + eligible job |
| Loading | Show inline progress on button; block double-tap |

Label: **Continue** (not Submit).

On tap:

1. Client-validate file (size, MIME, non-empty).
2. Re-check eligibility (not own job, not already applied, open).
3. Advance wizard to step 2 (`controller.currentStep = 1`) without uploading yet.

Upload happens on **Submit Application** in step 2 unless using an existing saved `cv_file_id`.

## Eligibility (disable Continue when)

| State | UI |
|-------|-----|
| Eligible | Normal step 1 |
| Already applied | Redirect or inline **Application already submitted** + link to status |
| Closed / expired / full | Explain; disable upload + Continue |
| Own job | **You posted this job** — manage applicants instead |
| Missing / forbidden job | Unavailable + Back |
