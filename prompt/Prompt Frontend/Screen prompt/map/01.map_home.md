# 01 - Map Home Prompt

Build the **Map** screen for Vithey App — nearby shops with Google-style location control.

## Product spec

### Quick info

| Field | Value |
|-------|-------|
| Screen ID | `map-01` |
| Route | `AppRoutes.map` (`/map`) |
| Flutter module | `lib/modules/map/` |
| Backend service(s) | `map-service` |
| Auth required | Yes |
| Competition feature | Yes |

### Purpose

Let users find shops/places around their GPS **or** another place they set as the search center.

### Open from

- Home header map icon
- Optional: Search “Places on map” row

### Main UI

| Element | Description |
|---------|-------------|
| Google Map | Full bleed; dark style in dark mode |
| Pill search | Radius 24, autocomplete dropdown |
| Filter chips / tune | category, radius, open_now, min_rating |
| My-location icon | Bottom-right teal circle (`AppColors.primary`) |
| Search this area | Pill after pan/zoom away from center |
| Place sheet | Pin tap — name, rating, distance, favorite, directions |
| Add place FAB (optional) | Local-only pins (`/add-place`) |

### User actions

| Action | Result |
|--------|--------|
| Tap my-location | Recenter GPS; `searchCenter = gps`; nearby reload |
| Long-press my-location | Back to me (reset center to GPS) |
| Pick autocomplete | Camera + “Search from here” marker; nearby |
| Long-press map | Sheet “Search around here” → set center |
| Search this area | Camera center becomes `searchCenter` |
| Tap pin | Place detail sheet |
| Favorite | POST/DELETE `/places/favorites` |

### Logic & behavior

- State: `gpsLatLng`, `searchCenter`, `isFollowingGps`
- All nearby/search send `searchCenter.lat/lng`
- Mock via `USE_MOCK_MAP` / `USE_MOCK_API`
- No Photon/Komoot; no Google API key on client
- Hide Google default my-location button; use custom icon
- Icons: `gps_fixed` when following GPS, `gps_not_fixed` otherwise

### Navigation

| From | Action | To |
|------|--------|-----|
| Home | Map icon | `/map` |
| Map | Add place | `/add-place` |
| Map | Back | Home |

### API endpoints

| Method | Path | Notes |
|--------|------|-------|
| GET | `/places/nearby` | lat, lng, radius_m, category, open_now, min_rating, price_level |
| GET | `/places/search` | query + same filters |
| GET | `/places/autocomplete` | input, lat, lng |
| GET | `/places/{google_place_id}` | detail |
| GET/POST/DELETE | `/places/favorites` | user favorites |
| GET/DELETE | `/places/history` | recent searches |
