## `NotificationIsarService`

class NotificationIsarService {
  Future<void> init() async { /* open Isar with LocalNotificationSchema */ }

  Stream<List<LocalNotification>> watchAll() =>
      isar.localNotifications.where().sortByCreatedAtDesc().watch(fireImmediately: true);

      isar.localNotifications.filter().isReadEqualTo(false).sortByCreatedAtDesc().watch(fireImmediately: true);

## Repository integration

```dart
class NotificationRepository {
  Stream<List<AppNotification>> watchNotifications({NotificationFilter filter}) {
    final stream = filter == NotificationFilter.unread
        ? _isar.watchUnread()
        : _isar.watchAll();
    return stream.map((list) => list.map(NotificationIsarMapper.fromLocal).toList());
  }

  Future<List<AppNotification>> fetchNotifications({required NotificationFilter filter, int page = 1}) async {
    List<AppNotification> remote;
    if (useMockApi) {
      remote = _mockNotifications(filter);
    } else {
      remote = await _service.getNotifications(page: page, unreadOnly: filter == NotificationFilter.unread);
    }
    await _isar.upsertAll(remote);
    return remote;
  }

  Future<void> upsertFromPush(AppNotification n) async {
    await _isar.upsert(n);
    _unreadCount.value = await _isar.unreadCount();
  }
}
```

## Sync strategy

```text
App open / Notification screen
    → Show Isar cache immediately (watch stream)
    → REST fetch page 1 in background
    → Upsert by notificationId (server wins on conflict)

FCM arrives
    → upsertFromPush (newer createdAt wins if same ID)

Mark read / delete
    → Optimistic Isar update
    → REST call
    → Rollback on failure

Logout
    → clearAll()
```

## Dedupe rules

| Key | Rule |
|-----|------|
| `notificationId` | Primary unique key |
| `dedupeKey` | Optional — `event:{eventId}` from backend |
| FCM + REST | Same `notificationId` → single row update, not duplicate |

## Stale indicator

When offline and cache age > 5 minutes, show subtle banner:

> **Showing saved notifications. Pull to refresh when online.**

Use `connectivity_plus` + `lastSyncedAt`.
