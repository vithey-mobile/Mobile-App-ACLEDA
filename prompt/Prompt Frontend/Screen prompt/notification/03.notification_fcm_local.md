# 03 — Firebase Cloud Messaging & Local Notifications

Implement push delivery and OS tray display using **`firebase_messaging`** + **`flutter_local_notifications`**.

## Dependencies

```yaml
dependencies:
  firebase_core: ^3.8.0
  firebase_messaging: ^15.1.0
  flutter_local_notifications: ^18.0.0

# .env
FCM_ENABLED=true
```

## Platform setup

### Android

1. Add `google-services.json` to `android/app/`
2. Apply Google Services plugin in `android/build.gradle` + `android/app/build.gradle`
3. Create notification channels (see below)
4. `AndroidManifest.xml`: `POST_NOTIFICATIONS` permission (API 33+)

### iOS

1. Add `GoogleService-Info.plist` to `ios/Runner/`
2. Enable Push Notifications + Background Modes (remote notifications) in Xcode
3. Request permission via `FirebaseMessaging.requestPermission()`

### Firebase Console

- Create project **Vithey**
- Register Android (`com.aub.vithey`) + iOS bundle IDs
- Upload APNs key for iOS
- Service account JSON for backend Firebase Admin SDK

## `LocalNotificationService`

```dart
class LocalNotificationService {
  final _plugin = FlutterLocalNotificationsPlugin();

  Future<void> init() async {
    const android = AndroidInitializationSettings('@mipmap/ic_launcher');
    const ios = DarwinInitializationSettings(
      requestAlertPermission: false,
      requestBadgePermission: false,
      requestSoundPermission: false,
    );
    await _plugin.initialize(
      const InitializationSettings(android: android, iOS: ios),
      onDidReceiveNotificationResponse: (details) {
        if (details.payload != null) {
          NotificationRouter.openFromFcmData(jsonDecode(details.payload!));
        }
      },
    );
    // Register Android channels
    final androidPlugin = _plugin.resolvePlatformSpecificImplementation<
        AndroidFlutterLocalNotificationsPlugin>();
    for (final ch in NotificationChannels.all) {
      await androidPlugin?.createNotificationChannel(ch);
    }
  }

  Future<void> show(AppNotification n) async {
    final channel = _channelFor(n.type);
    await _plugin.show(
      n.id.hashCode,
      n.title,
      buildDisplayText(n),
      NotificationDetails(
        android: AndroidNotificationDetails(
          channel.id,
          channel.name,
          channelDescription: channel.description,
          importance: channel.importance,
          priority: Priority.high,
          largeIcon: /* actor avatar bytes if cached */,
        ),
        iOS: const DarwinNotificationDetails(),
      ),
      payload: jsonEncode(n.toFcmData()),
    );
  }
}
```

## `FcmService`

```dart
class FcmService {
  FcmService(this._notificationRepo, this._localNotifications, this._api);

  bool get enabled => dotenv.env['FCM_ENABLED']?.toLowerCase() == 'true';

  Future<void> init() async {
    if (!enabled) return;
    await Firebase.initializeApp();
    await _localNotifications.init();

    final settings = await FirebaseMessaging.instance.requestPermission(
      alert: true, badge: true, sound: true,
    );
    if (settings.authorizationStatus == AuthorizationStatus.denied) return;

    await _registerToken();

    FirebaseMessaging.instance.onTokenRefresh.listen(_registerToken);

    FirebaseMessaging.onMessage.listen(_onForegroundMessage);
    FirebaseMessaging.onMessageOpenedApp.listen(_onBackgroundTap);

    final initial = await FirebaseMessaging.instance.getInitialMessage();
    if (initial != null) _onBackgroundTap(initial);
  }

  Future<void> _registerToken([String? token]) async {
    token ??= await FirebaseMessaging.instance.getToken();
    if (token == null) return;
    await _api.post('/notifications/devices', data: {
      'fcm_token': token,
      'platform': Platform.isIOS ? 'IOS' : 'ANDROID',
    });
  }

  void _onForegroundMessage(RemoteMessage message) {
    final notification = AppNotification.fromFcmData(message.data);
    if (notification == null) return;
    _notificationRepo.upsertFromPush(notification);
    _localNotifications.show(notification); // heads-up while in app
  }

  void _onBackgroundTap(RemoteMessage message) {
    // Auth must be valid — hydrate from server if needed
    NotificationRouter.openFromFcmData(message.data);
  }

  Future<void> unregisterToken() async {
    if (!enabled) return;
    final token = await FirebaseMessaging.instance.getToken();
    if (token != null) {
      await _api.delete('/notifications/devices/$token');
    }
    await FirebaseMessaging.instance.deleteToken();
  }
}
```

## Foreground vs background behavior

| App state | FCM handler | UI behavior |
|-----------|---------------|-------------|
| Foreground | `onMessage` | Upsert inbox + optional heads-up via local notifications |
| Background | System tray (data+notification payload) | Tray tap → `onMessageOpenedApp` |
| Terminated | System tray | `getInitialMessage` on cold start |

## Permission UX

- **Do not** request permission on first app frame
- Request after login success OR when user enables notifications in Settings
- If denied: inbox still works via REST; show subtle banner in notification screen

## Logout / account switch

```dart
await fcmService.unregisterToken();
await notificationRepository.clearCache();
```

## Security rules (push payload)

| Never include | Why |
|---------------|-----|
| CV file URL | PII |
| Full chat message body | Privacy |
| Payment card / bank details | PCI |
| JWT or refresh token | Security |
| Student ID number | PII |

Use opaque IDs + fetch authoritative detail after tap with auth.

## Background handler (top-level)

```dart
@pragma('vm:entry-point')
Future<void> firebaseMessagingBackgroundHandler(RemoteMessage message) async {
  await Firebase.initializeApp();
  // Optional: persist to Isar for offline inbox
}
```

Register in `main.dart`:

```dart
FirebaseMessaging.onBackgroundMessage(firebaseMessagingBackgroundHandler);
```
