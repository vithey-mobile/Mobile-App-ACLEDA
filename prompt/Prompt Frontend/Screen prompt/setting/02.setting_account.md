# 02 - Settings Account Prompt

Build the **Account** settings screen for Vithey App in Flutter, matching:

- `Prompt Frontend/screen image/setting/setting_account.png`

## Quick info

| Field | Value |
|---|---|
| Route | `Routes.SETTING_ACCOUNT` |
| Flutter module | `lib/modules/settings/account/` or `lib/modules/settings/` |
| Backend services | `user-profile-service`, `file-service` |
| Auth required | Yes |

## Goal

Show the current user's profile/account information and support avatar/profile editing.

## Visual requirements

Match `setting_account.png`:

- White background.
- App bar:
  - Back arrow.
  - Bold title: **Account**.
  - Bottom divider.
- Centered circular avatar near top.
- Small teal camera floating button overlapping bottom-right of avatar.
- Teal **Edit Info** action below avatar with pencil icon.
- Account info shown as stacked cards/fields:
  - Full Name
  - Email
  - Phone
  - Academic Info
- Each field:
  - Grey leading icon and label row.
  - Value below.
  - Rounded white card with subtle shadow/divider.
- Bottom navigation remains visible with Profile selected.

## Data fields

| UI label | Model field | Source |
|---|---|---|
| Full Name | `full_name` | `/users/me` |
| Email | `email` | `/auth/me` or auth user cached after login |
| Phone | `phone` | `/auth/me` or profile extension if backend supports |
| Academic Info | `major`, `year`, `term`, `university` | `/users/me` |
| Avatar | `avatar_url` / `avatar_file_id` | `/users/me` + file-service |

If email/phone are not returned by `user-profile-service`, use cached auth user from login or `GET /auth/me`.

## Controller behavior

- `loadAccount()`:
  - Load cached user/profile for instant paint.
  - Fetch `GET /users/me`.
  - Optionally fetch `GET /auth/me` for email/phone.
- `changeAvatar()`:
  - Open image picker/camera sheet.
  - Upload selected image via `POST /files/upload` with `type=AVATAR`.
  - Save avatar via `PATCH /users/me/avatar`.
  - Update local UI immediately from response.
- `openEditInfo()`:
  - Show bottom sheet or navigate to edit account screen.
  - Editable fields: full name, bio, phone if supported, university, major, graduation year.

## API

| Method | Path | Notes |
|---|---|---|
| `GET` | `/api/v1/users/me` | Current profile |
| `GET` | `/api/v1/auth/me` | Current auth info (email/phone/role) |
| `PATCH` | `/api/v1/users/me` | Update profile fields |
| `POST` | `/api/v1/files/upload` | Upload avatar with `type=AVATAR` |
| `PATCH` | `/api/v1/users/me/avatar` | Save avatar file/url |

Use `Prompt Frontend/api-intergration/integration-contract.md`.

## Empty/error states

- Avatar missing: show `AppLogo` or initials fallback.
- Profile loading: skeleton cards.
- Profile load error: `AppErrorWidget` with Retry.
- Avatar upload failure: snackbar + keep previous avatar.

## Testing

- Renders avatar and all four visible info groups.
- `Edit Info` opens edit flow.
- Avatar upload sends multipart type `AVATAR`.
- Failed update does not clear current data.

## Output

Complete Account settings screen matching `setting_account.png`, wired to profile/auth/file repositories.
