# 02 - Settings Account Prompt

Build the **Account** settings screen for Vithey App in Flutter.

## Quick info

| Field | Value |
|---|---|
| Route | `AppRoutes.settingsAccount` (`/settings/account`) |
| Flutter module | `lib/modules/settings/account/` |
| Backend services | `user-profile-service`, `auth-service`, `file-service` |
| Auth required | Yes |
| Entry point | Settings Home → Account |

## Goal

Show the current user’s **private personal / identity** data only.

- **Account** = private account identity (name, email, phone, DOB, gender, location, avatar, student verification).
- **Edit Profile** (`/profile/edit`) = public / professional presence (bio, skills, work, education, links, public contact).

Do **not** show or edit professional profile fields here (skills, bio, work, education, social links, stats).

## Visual requirements

Match the **Settings home** visual system (not the old elevated shadow cards from the legacy PNG):

- Page background: light gray (`#F2F2F2`) in light mode; themed body in dark mode.
- Use `SettingsScaffold` (collapsing large title → centered compact title on scroll).
- White (or `cardSurface`) rounded groups (`borderRadius: 12`), **no** heavy shadows, **no** dividers between rows.
- Rows: primary-colored leading icon + label + muted value subtitle + chevron when tappable.
- Bottom navigation remains visible with **Profile** selected.

### Profile header card

- Centered circular avatar.
- Teal camera button on avatar → change avatar (gallery).
- Display full name under avatar.
- Muted caption: `Private account information`.
- Outline button: **Edit personal info** → `AppRoutes.settingsEditAccount`.

### Sections

#### Personal (read-only list on this screen)

| UI label | Model field | Notes |
|---|---|---|
| Full name | `fullName` | Display; edit on Edit Account |
| Email | `email` | Display; change via Google on Edit Account |
| Phone | `phone` | Display |
| Date of birth | `dateOfBirth` | Formatted `MMMM dd, yyyy` |
| Gender | `gender` | Display |
| Location | `location` | Display |

Empty values show muted `Not set`.

#### Verification

| UI label | Model field | Notes |
|---|---|---|
| Student verification | `isStudentVerified` | Subtitle `Verified student` / `Not verified`; tap → `AppRoutes.studentVerification` |

## Explicitly out of scope (Edit Profile owns these)

| Field / area | Reason |
|---|---|
| Bio, skills, work, education, links | Professional / public profile |
| Telegram / Facebook / portfolio | Public links |
| Followers / following / posts / likes | Profile stats |
| Inline text fields on Account | Editing happens on Edit Account via bottom sheets |

## Controller behavior

- `loadAccount()` — `ProfileRepository.getProfile(currentUserId)`.
- `changeAvatar()` — gallery picker → update avatar (upload when file API available).
- `openEditInfo()` — `Get.toNamed(AppRoutes.settingsEditAccount)`; reload if `result == true`.

## API

| Method | Path | Notes |
|---|---|---|
| `GET` | `/api/v1/users/me` | Current profile |
| `GET` | `/api/v1/auth/me` | Optional email/phone fallback |
| `POST` | `/api/v1/files/upload` | Avatar (`type=AVATAR`) |
| `PATCH` | `/api/v1/users/me/avatar` | Save avatar |

## Empty / error states

- Loading: `LoadingWidget`.
- Error: `AppErrorWidget` + Retry.
- Missing strings: `Not set`.
- Avatar missing: initials fallback via `UserAvatar`.
