# 04 - Settings Help Center Prompt

Build the **Help Center** settings screen for Vithey App in Flutter.

> No specific reference image is provided. Match the visual language from `setting_home.png`: white background, simple app bar, rounded cards, grey icons, teal accents.

## Quick info

| Field | Value |
|---|---|
| Route | `Routes.SETTING_HELP_CENTER` |
| Flutter module | `lib/modules/settings/help_center/` or `lib/modules/settings/` |
| Backend service | Optional / none for MVP |
| Auth required | Yes |

## Goal

Provide support options and frequently asked questions for students using Vithey.

## UI requirements

- App bar:
  - Back arrow.
  - Bold title: **Help Center**.
  - Divider below.
- Search field:
  - Placeholder: **Search help topics**
  - Rounded light-grey input.
- Quick support card:
  - Title: **How can we help?**
  - Subtitle: **Find answers or contact support.**
- FAQ sections as rounded tiles:
  - Account & Login
  - Student Verification
  - Finance
  - Jobs & CV
  - Chat & Safety
  - AI Assistant
- Contact support card:
  - **Contact Support**
  - Email support action.
  - Optional Telegram/Facebook support link if configured.
- Bottom navigation remains visible with Profile selected.

## Architecture

```text
lib/modules/settings/help_center/
  help_center_screen.dart
  help_center_controller.dart
  help_center_binding.dart
  widgets/
    help_search_field.dart
    faq_category_tile.dart
    contact_support_card.dart
```

## Controller behavior

- `query` filters local FAQ categories/items.
- `openFaqCategory(categoryId)` opens a detail bottom sheet or route.
- `contactSupport()` launches mail app via `url_launcher`.

## Content

Use local static content for MVP:

| Category | Example topics |
|---|---|
| Account & Login | Reset password, update email, logout |
| Student Verification | Accepted documents, pending status |
| Finance | Payment alerts, invoice detail |
| Jobs & CV | Upload CV, apply to job, applicant review |
| Chat & Safety | Message requests, block/report |
| AI Assistant | Topics, privacy, unavailable provider |

## API

None required for MVP.

Optional future endpoint:

| Method | Path | Notes |
|---|---|---|
| `GET` | `/api/v1/help/articles` | Server-managed help content |

## Testing

- Search filters FAQ items.
- Contact support launches a valid URI or shows fallback.
- No dead actions.

## Output

Complete Help Center screen consistent with Settings styling.
