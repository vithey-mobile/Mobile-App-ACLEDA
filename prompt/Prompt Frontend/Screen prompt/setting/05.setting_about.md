# 05 - Settings About Prompt

Build the **About** settings screen for Vithey App.

> No specific reference image is provided. Match the visual language from `setting_home.png`: white background, app bar, rounded cards, teal accents.

## Quick info

| Field | Value |
|---|---|
| Route | `Routes.SETTING_ABOUT` |
| Flutter module | `lib/modules/settings/about/` or `lib/modules/settings/` |
| Backend service | None |
| Auth required | Yes |

## Goal

Show app identity, version information, competition context, legal links, and credits.

## UI requirements

- App bar:
  - Back arrow.
  - Bold title: **About**
  - Divider below.
- Header:
  - Official `AppLogo`.
  - App name: **Vithey**
  - Subtitle: **AUB student community app**
  - Version text from package info.
- Info card:
  - **About Vithey**
  - Short app description:
    - Connect with students
    - Apply for jobs with CV
    - Track finance
    - Chat privately
    - Use AI support
- Competition card:
  - **ACLEDA Bank AUB App Competition**
  - Link to official competition site.
- Legal/support rows:
  - Privacy Policy
  - Terms of Service
  - Licenses
  - Contact Support
- Bottom navigation remains visible with Profile selected.

## Architecture

```text
lib/modules/settings/about/
  about_screen.dart
  about_controller.dart
  about_binding.dart
  widgets/
    about_header.dart
    about_info_card.dart
    about_link_tile.dart
```

## Dependencies

Add if not already present:

```yaml
package_info_plus: latest
```

Use `url_launcher` for external links.

## Controller behavior

- `loadPackageInfo()` gets version/build number.
- `openPrivacyPolicy()`, `openTerms()`, `openCompetitionRules()` use `url_launcher`.
- `showLicenses()` calls Flutter `showLicensePage`.

## API

None.

## Testing

- App name/logo render.
- Version loads from package info.
- Links have real actions or are hidden.
- License page opens.

## Output

Complete About screen with app version, links, and competition context.
