# 04 — Chat Isar Offline Cache

Local persistence layer for offline-first private chat.

## Why Isar

| Need | Isar solution |
|------|---------------|
| Instant list open | Read conversations from disk first |
| Offline read history | Cache messages per conversation |
| Send while flaky network | Outbox queue with retry |
| Dedupe REST + WS | Unique index on `messageId` |

## Schemas

### `LocalConversation`

```dart
@collection
class LocalConversation {
  Id get isarId => fastHash(conversationId);
  @Index(unique: true)
  late String conversationId;
  late String participantId;
  late String participantName;
  String? participantAvatarUrl;
  bool participantIsOnline = false;
```

## `IsarService` API

```dart
class IsarService {
  Future<void> init();
  Future<void> clearAll(); // logout

  // Conversations
  Stream<List<LocalConversation>> watchConversations();
  Future<void> upsertConversation(LocalConversation conv);
  Future<void> setUnreadCount(String conversationId, int count);

  // Messages
  Stream<List<LocalChatMessage>> watchMessages(String conversationId);
  Future<List<LocalChatMessage>> getMessages(String conversationId, {int limit = 30, int offset = 0});
  Future<void> upsertMessage(LocalChatMessage msg);
  Future<void> markMessageDeleted(String messageId);

  // Outbox
  Future<void> enqueueOutbox(PendingOutboxMessage msg);
  Future<List<PendingOutboxMessage>> pendingOutbox();
  Future<void> removeOutbox(String clientId);
}
```

## Sync strategy

### Conversation list

```text
1. UI subscribes to watchConversations() → instant render
2. REST GET /conversations → upsert each → Isar emits update
3. STOMP message → upsert conversation preview + unread in Isar
```

### Message thread

```text
1. Open thread → watchMessages(conversationId) from Isar
2. REST GET /conversations/{id}/messages → merge pages into Isar
3. STOMP inbound → upsert message if message_id new
4. Send → insert LocalChatMessage(sending) + PendingOutbox → try send → remove outbox on ack
```

### Stale indicator

If `lastSyncedAt` older than 5 minutes and offline:

```dart
Banner(message: 'Showing cached messages. Connect to refresh.')
```

## Dedupe rules

| Key | Rule |
|-----|------|
| `messageId` | Server UUID wins over temp client id |
| `clientId` | Replace optimistic row when server ack includes same `client_message_id` |
| WS + REST echo | Ignore second insert with same `messageId` |

## Outbox retry

`ChatSyncService` background loop:

1. Read `pendingOutbox()` ordered by `createdAt`
2. If online: POST or STOMP send
3. On success: remove outbox, update message status
4. On failure: increment `attemptCount`; backoff; max 5 attempts then mark `failed`

## Repository integration

`ChatRepository` becomes the single entry:
