## Data & API (target)

| Tab | Endpoint *(planned)* |
|-----|---------------------|
| Medias | `GET /conversations/{id}/attachments?type=IMAGE` |
| Videos | `GET /conversations/{id}/attachments?type=VIDEO` |
| Files | `GET /conversations/{id}/attachments?type=FILE` |
| Links | `GET /conversations/{id}/attachments?type=LINK` |

Until backend exists:

- Return empty lists in production
- Mock provider may return fixture items for UI dev **only** when `USE_MOCK_API=true`

Current chat-service is **text-only** — tabs must render with empty states, not crash.

## Safety actions (overflow menu)

### Block

`ConfirmDialog` → `POST /conversations/{id}/block` → `Get.close(2)` + snackbar

### Report

Dialog with reason `TextField` → `POST /users/{userId}/report`

Reporting does not auto-block unless user confirms.

## Online / privacy rules

- Presence from server `is_online` / `last_seen_at` only
- Respect hidden last-seen privacy flag
- Phone/bio hidden when policy denies
- Shared media via short-lived signed URLs
- Clear cached profile on logout
