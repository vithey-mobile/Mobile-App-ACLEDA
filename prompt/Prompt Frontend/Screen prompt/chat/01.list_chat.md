# 01 — Chat List (Vithey Messenger Style)

Build the **conversation list** from `Prompt Frontend/screen image/chat/listchat.png`.

| Field | Value |
|-------|-------|
| Screen ID | `13A` |
| Route | `AppRoutes.chat` |
| Module | `lib/modules/chat/` |
| Backend | `chat-service` :8087 |

| Entry | Bottom navigation — **Chat** tab active (teal pill) |

## Goal

Show the user's private conversations in a clean Vithey-branded inbox with quick Add Chat access, real-time preview updates, unread badges, and read indicators.

## Branded app bar (`chat_list_app_bar.dart`)

| Element | Spec |
|---------|------|
| Left | `AppLogo` small (~28dp) + **Vithey** wordmark, bold, `context.appColors.heading` |
| Right | `Icons.search_outlined` — opens contact/conversation search sheet |
| Background | White / `context.appColors.bodyBackground` |
| Elevation | 0; optional 1px bottom divider |

Do not use a generic `AppBar` title only — match logo + name from reference.

## Add Chat row (`add_chat_contacts_row.dart`)

Horizontal `ListView` below app bar:

| Item | Spec |
|------|------|
| **Add Chat** (first) | Teal filled circle `56dp` with white `+`; label **Add Chat** below, `12sp` muted |
| Contact avatars | `56dp` circle `UserAvatar`; name below, 1 line ellipsis, `12sp` |
| Active ring | Thin **teal ring** (`2dp`) around avatar when `isOnline == true` or story/active flag |
| Tap Add Chat | Debounced user search bottom sheet → pick user → open thread or message request |
| Tap contact | `openConversation` if exists, else `startChatWithUser` |

Fixture names from reference (mock only): Heng Liza, Meas Lily, Moeng Kimheang, Ponloeng Bora.

**Never** auto-send a default first message when starting a chat.

## Messages section header

- Label: **Messages** — `titleMedium`, bold, left-aligned, `16dp` horizontal padding, `12dp` top padding
- Optional: message-request badge count on header when `GET /message-requests` returns pending items

## Conversation row (`conversation_list_tile.dart`)

Full-width row, min height `72dp`, no card elevation (flat list):

| Zone | Spec |
|------|------|
| Avatar | `UserAvatar` **52dp** left; optional teal online ring (same as Add Chat row) |
| Title row | Participant `fullName` — semibold; unread uses `FontWeight.w700` |
| Subtitle | Last message preview **or** **Typing…** in **teal** (`AppColors.primary`) when typing event active |
| Own-message prefix | When last message sender is current user: prefix **You:** before preview text |
| Trailing top | **Unread:** teal circle badge, white count, min `20dp`, cap `99+` **OR** **Read:** teal `done_all` double-check when `unread_count == 0` and own last message `READ` |
| Trailing bottom | Relative time — **2m ago**, **Yesterday**, **3d ago** via `RelativeTime.format()`; `11–12sp` muted |
| Tap | `openConversation(conversationId)` |
| Long press | Bottom sheet: Mute, Block, Report, Delete chat *(feature-gate)* |

## Bottom navigation (Chat tab active)

Compose existing app bottom nav; when Chat route is active:

| Item | State |
|------|-------|
| Chat icon + label | Teal icon/text inside **light teal pill** background (~12dp radius) |
| Center FAB | Large teal `+` (create post) — unchanged from Home |
| Other tabs | Muted gray |

List content must add bottom padding so last row is not hidden behind nav + FAB.

## Message requests section

Render **above** Messages list when pending requests exist (not shown in `listchat.png` but required by product):

- Compact card per request: avatar, name, snippet, **Accept** / **Decline**
- `POST /conversations/{id}/accept` | `decline`
- Do not mix PENDING threads into active list without label

## Real-time list updates

1. Subscribe STOMP `/user/queue/messages` (see `05`)
2. On inbound: upsert conversation, move to top, update preview + `updated_at`
3. Increment `unread_count` only if `conversationId != activeConversationId`
4. De-duplicate by `message_id`
5. Write through to Isar (`04`)

Typing: update subtitle to **Typing…** only on server typing event; clear on stop/TTL.

## Offline / Isar-first load

1. Render Isar cache immediately
2. Parallel `GET /conversations` → merge → refresh
3. Offline: `OfflineBanner` or inline "Showing cached messages"

## API

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/conversations?page=&limit=` | Paginated list |
| GET | `/message-requests` | Pending requests |
| POST | `/conversations/request` | New request |
| POST | `/conversations/{id}/accept` | Accept |
| POST | `/conversations/{id}/decline` | Decline |
