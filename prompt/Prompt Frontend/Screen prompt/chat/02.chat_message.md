# 02 — Chat Message Thread (Vithey Style)

Build the **private message thread** from `Prompt Frontend/screen image/chat/chatuser.png`.

| Field | Value |
|-------|-------|
| Screen ID | `13B` |
| Route | `AppRoutes.chatDetail` |
| Args | `ChatDetailArgs(conversationId)` |
| Module | `lib/modules/chat/` |

## Goal

Deliver a real-time 1:1 thread with teal outgoing bubbles, bordered incoming bubbles, **Seen** receipts, and a pill-shaped composer matching the reference.

## Screen chrome

| Element | Spec |
|---------|------|
| Background | Light gray `#F5F7FA` or `context.appColors.inputFill` — **not** pure white |
| Safe area | Respect top/bottom; composer above keyboard |

## Header (`chat_detail_header.dart`)

White bar, `1px` bottom border `context.appColors.border`:

| Element | Spec |
|---------|------|
| Back | `Icons.arrow_back` |
| Avatar | `40dp` circle — tap with name opens profile (`03`) |
| Title | Participant name bold — e.g. **Heng Liza** |
| Subtitle | **Active Now** when `isOnline`; else **Last seen …** from server only |
| Search | `Icons.search_outlined` right — in-chat search *(feature-gate)* |
| Overflow | `⋮` menu: View profile, Mute, Block, Report |

Subtitle must be `12–13sp` muted gray/teal for Active Now.

## Message bubbles (`message_bubble.dart`)

### Outgoing (own) — right aligned

| Property | Value |
|----------|-------|
| Background | `AppColors.primary` solid teal |
| Text | White `15sp`, line height `1.4` |
| Radius | `16dp`; **bottom-right `4dp`** tail |
| Max width | `78%` screen width |
| Padding | `12dp` horizontal, `8dp` vertical |
| Timestamp | Inside bubble, bottom-right, white `70%` opacity, e.g. **9:27PM** |
| Below bubble | **Seen** label — small gray `11sp`, right-aligned, only when `status == read` |

Reference uses the word **Seen** under the bubble, not only ✓✓ icons. Support both:

- Primary: text **Seen** below last read own message
- Optional: small teal double-check next to timestamp inside bubble

### Incoming (other) — left aligned

| Property | Value |
|----------|-------|
| Avatar | `32dp` left of bubble; show on **first message in consecutive group** only |
| Background | White `context.appColors.cardSurface` |
| Border | `1dp` `context.appColors.border` |
| Text | `context.appColors.heading` |
| Radius | `16dp`; **bottom-left `4dp`** tail |
| Timestamp | Inside bubble bottom-right, muted `11sp`, e.g. **9:15PM** |

### Grouping

- Consecutive messages from same sender within 2 min: hide repeated avatar, reduce top spacing to `4dp`
- Different sender or >2 min gap: `12dp` spacing + avatar

## Read / delivery status (`message_status_label.dart`)

```dart
enum MessageDeliveryStatus { sending, sent, delivered, read, failed }
```

| Status | UI on own messages |
|--------|-------------------|
| `sending` | No Seen; optional clock icon |
| `sent` / `delivered` | No Seen yet |
| `read` | **Seen** text below bubble (reference) |
| `failed` | Red tint + Retry tap |

Update from REST ack, STOMP events, and `PATCH /messages/{id}/read`.

## Date separators (`date_separator.dart`)

- Centered muted pill when calendar day changes: **Today**, **Yesterday**, or `MMMM d, yyyy`
- Not shown in reference crop but required for long threads

## Typing indicator (`typing_indicator_banner.dart`)

- Above composer: `{name} is typing…` with animated dots
- Only when server typing STOMP event active
- **Do not** fake typing on keystrokes until `/app/chat.typing` is wired

## Composer (`chat_composer.dart`)

Match pill design from reference:

| Element | Spec |
|---------|------|
| Container | Full width, `48–52dp` height, `24dp` border radius, fill `context.appColors.inputFill` |
| Placeholder | **Write comment…** — use `AppStrings.chatComposerHint` (reference copy; not "message") |
| Input | `TextField` multiline `1–4` lines, no visible border, `16dp` left padding |
| Send button | **Circular** `44dp` teal button, white `Icons.send` / paper plane, **overlapping** right inside pill |
| Disabled send | When trimmed text empty — gray button |
| Attach | Hidden until attachment contract exists |

## Send lifecycle

```text
validate → optimistic insert (sending) → Isar outbox
  → STOMP /app/chat.send OR POST /conversations/{id}/messages
  → ack → sent → delivered → read (Seen appears)
```

Retry reuses `client_message_id` — never duplicate bubble.

## Pagination & scroll

- Newest at bottom; `ListView` with optional `reverse: true`
- Initial: last 30 from Isar + REST page 1
- Scroll up → older messages; preserve anchor
- `jump_to_latest_chip.dart` when scrolled up >120px

## Read receipts

Mark peer messages read when thread is foreground, visible, and not yet `read`. Batch `PATCH` every 500ms.

## API

| Method | Path |
|--------|------|
| GET | `/conversations/{id}/messages?page=&limit=` |
| POST | `/conversations/{id}/messages` |
| PATCH | `/messages/{id}/read` |

```json
{
  "text": "Sure! Send me your CV",
  "client_message_id": "client-1735123456789",
  "reply_to_message_id": null
}
```

## States

| State | UI |
|-------|-----|
| Loading | Shimmer bubbles |
| Empty | Centered "Say hello!" |
| Blocked | Composer disabled + banner |
| Pending request | "Accept request to reply" |
| Offline | Cached thread + connection banner |
| Send failed | Bubble error state + Retry |

## Dark mode

- Chat background: `context.appColors.bodyBackground` (darker gray)
- Incoming bubble: `cardSurface` + border
- Outgoing: keep `AppColors.primary`; white text
- **Seen** label: `context.appColors.muted`
