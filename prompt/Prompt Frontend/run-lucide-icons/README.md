# GLM 5.3 Flash — Lucide icons (single prompt)

**One chat only.**

## Run

1. Open **1** GLM chat.
2. Open [`ONE_SHOT.md`](ONE_SHOT.md).
3. Copy **everything below the `---` line** → paste → wait until done.

## What it does

- Creates Lucide barrel (`core/icons/vithey_icons.dart`)
- Swaps all Material `Icons.*` → `LucideIcons.*` (modules + kit)
- Keeps modules free of direct `shadcn_flutter` imports
