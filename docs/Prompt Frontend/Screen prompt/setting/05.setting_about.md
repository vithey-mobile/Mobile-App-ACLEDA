# 05 - Settings About Prompt

Build the **About** settings screen for Vithey App in Flutter, matching:

- `Prompt Frontend/screen image/setting/setting_about.png`

## Quick info

| Field | Value |
|---|---|
| Route | `Routes.SETTING_ABOUT` |
| Flutter module | `lib/modules/settings/about/` |
| Backend service | None |
| Auth required | Yes |
| Entry point | Settings Home → About |

## Goal

Show app identity, version, mission, core features, and contact information.

## Visual requirements

Match `setting_about.png`, aligned with Settings Home and Privacy/Security screen styling (`01.setting_home.md`, `03.setting_privacy.md`, `03.setting_security.md`). All colors must come from `Theme.of(context)` / `colorScheme` / semantic app colors so the screen looks correct in **both light and dark mode** — never hardcode white, black, or teal hex values.

- Theme background (`scaffoldBackgroundColor`).
- App bar:
  - Back arrow on left.
  - Bold title: **About**.
  - Thin divider below.
  - Reuse `settings_scaffold.dart`.
- Cards use surface color (`cardSurface`), soft shadow (`subtleShadow`), rounded corners (~12), matching the Privacy/Security cards.
- Bottom navigation remains visible with **Profile** selected, matching the app shell.

## Screen content

Render the following sections, top to bottom:

### Header (centered)

- Official `AppLogo` (circular container must adapt to theme, not a hardcoded white circle in dark mode).
- App name: **Vithey** — bold, heading color.
- Subtitle: **AUB Student Community App** — muted color.
- Version from package info, e.g. **Version 1.1** — muted, smaller.

### About Vithey card

- Title: **About Vithey**
- Short description, 2–3 lines, body text in heading color:
  - `Connect with students, apply for jobs with your CV, track finance, chat privately, and use AI support — all in one app built for the AUB community.`

### Mission card

- Title: **Mission**
- One concise paragraph, e.g.:
  - `Empower AUB students to connect, grow their skills, and manage student life in one place.`

### Core Features card

- Title: **Core Features**
- Bullet list (primary-colored bullet/icon, text in heading color):
  - Social Feed
  - Career & Jobs
  - Skill Tracking
  - Learning Roadmap
  - School Fee Tracking
  - Private Chat
  - AI Assistant

### Contact card

- Section title: **Contact**
- Info rows with primary-colored leading icon, label, and value; tappable where applicable:
  - Phone — opens dialer (`tel:`)
  - Email — opens mail app (`mailto:`)
  - Website — opens browser
  - Location — plain text (or opens maps if a URL is configured)

## Architecture

```text
lib/modules/settings/about/
  about_screen.dart
  about_controller.dart
  about_binding.dart
  widgets/
    about_header.dart
    about_info_card.dart
    about_feature_list_card.dart
    about_contact_card.dart
```

Reuse shared settings styling where possible:

- Rows: `settings_menu_tile.dart` with primary icons, `settings_tile_divider.dart` for inset dividers.
- Scaffold: `settings_scaffold.dart` for app bar + divider.
- Card style: match `privacy_switch_card.dart` (surface color, soft shadow, radius 12).

## Dependencies

Already present — do not re-add:

```yaml
package_info_plus: latest
url_launcher: latest
```

## Controller behavior

- `loadPackageInfo()` gets version/build number for the header.
- `openWebsite()` uses `url_launcher` (external browser).
- `callPhone()` uses `tel:`, `sendEmail()` uses `mailto:`.
- If a contact value is not configured, hide the row — do not show dead links.

## API

None.

## UX rules

- Every surface, text, icon, and shadow color must adapt to theme — verify the header logo container, cards, and link colors are legible in dark mode.
- Section/link icons and bullets use **primary color**; body text uses heading color; subtitles use muted color.
- Keep copy short and readable; no marketing walls of text.

## Testing

- Header renders logo, name, subtitle, and version from package info.
- All five sections render in order: header, About Vithey, Mission, Core Features, Contact.
- Core Features lists all seven features.
- Contact rows launch dialer/mail/browser correctly.
- Screen is legible and correctly tinted in both light and dark mode.

## Output

Complete About screen matching `setting_about.png`, fully theme-aware for light and dark mode, with version info, mission, core features, and contact details.
