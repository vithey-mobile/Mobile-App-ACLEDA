# 01 - Settings Home Prompt

Build the **Settings Home** screen for Vithey App in Flutter, matching:

- `Prompt Frontend/screen image/setting/setting_home.png`

## Quick info

| Field | Value |
|---|---|
| Route | `Routes.SETTINGS` |
| Flutter module | `lib/modules/settings/` |
| Backend services | `user-profile-service`, `auth-service` |
| Auth required | Yes |
| Entry point | Profile tab/settings gear |

## Goal

Show a grouped settings menu where the user can open Account, Privacy, Language, Notifications, Security, Help Center, About, toggle Dark Mode, and log out.

## Visual requirements

Match `setting_home.png`:

- White/light background.
- Safe-area top with app bar:
  - Back arrow on left.
  - Bold title: **Settings**.
  - Thin divider below.
- Section card:
  - Use elevated cards with soft shadows to create a floating, pop-up appearance. Each section should feel slightly raised above the background, with rounded corners, subtle depth, and clear separation between sections.
- Section labels:
  - **Preferences**
  - **System**
  - **Support**
- Rows are simple, full-width, white cards/tiles with:
  - Left outline icon with primary color.
  - Label.
  - Optional subtitle for Language (`English (US)`).
  - Right chevron for navigable rows with primary color.
- Dark Mode row uses a switch, not a chevron. have same height as row items in System section.
- **Language picker bottom sheet** (opened from Language row):
  - Modal bottom sheet with rounded top corners and safe-area padding.
  - Bold title at top: **Select Language**.
  - Inner rounded white card with soft shadow containing **2 language options**:
    - **English (US)** — subtitle: `English`
    - **Khmer** — subtitle: `ភាសាខ្មែរ`
  - Each option row:
    - Left **primary-colored globe icon** (`Icons.language_outlined`, size ~22).
    - Center text column: bold primary label + muted secondary subtitle below.
    - Right **primary-colored check/tick icon** (`Icons.check`) only on the currently selected language.
    - Inset divider between rows (aligned after icon column, not full-bleed).
  - Tapping an option saves the language, closes the sheet, and updates the Language row subtitle on Settings Home.
- Logout is a full-width pale-red background and rounded button with red icon/text in the center of button. 
- Bottom navigation remains visible with **Profile** selected, matching the app shell.

## Controller behavior

- `loadSettings()` reads local theme/language first, then optionally `GET /users/me/settings`.
- `toggleDarkMode(bool value)` updates `Get.changeThemeMode`, persists locally, and syncs with `PATCH /users/me/settings`.
- `openLanguagePicker()` opens `LanguagePickerSheet` bottom sheet with **English (US)** and **Khmer** options (globe icon, label, subtitle, primary tick on selected).
- `logout()`:
  1. Show `ConfirmDialog`.
  2. Call `AuthRepository.logout()` best effort.
  3. Clear secure/local session data.
  4. `Get.offAllNamed(Routes.AUTH)`.

## API

| Method | Path | Notes |
|---|---|---|
| `GET` | `/api/v1/users/me/settings` | Load remote preferences |
| `PATCH` | `/api/v1/users/me/settings` | Save theme/language/notifications |
| `POST` | `/api/v1/auth/logout` | Revoke refresh token |

Use `Prompt Frontend/api-intergration/integration-contract.md`.
