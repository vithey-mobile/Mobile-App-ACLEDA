## Architecture (Clean + GetX)

```text
UI (chatbot_screen + widgets)
        ↓
ChatbotController          ← orchestration only, no Dio
        ↓
AiRepository               ← mock/real switch, error mapping
        ↓
AiService                  ← Dio calls, SSE parser
        ↓
API Gateway :8080 → ai-service :8089 (Python)
```

## Current API (shipped — integrate now)

Source: `Prompt Backend/services/ai-service/API_ENDPOINTS.md`

### POST `/ai/chat`

**Request:**

```json
{
  "message": "How can I improve my CV?",
  "session_id": "uuid-or-null",
  "topic": "CV",
  "client_message_id": "client-1735123456789"
}
```

| Field | Rule |
|-------|------|
| `message` | Required, trimmed, max 4000 chars |
| `session_id` | Null on first message; required on follow-ups |
| `topic` | Optional: `CV`, `JOB`, `INTERVIEW`, `STUDENT`, `FINANCE` |
| `client_message_id` | Optional idempotency key from Flutter |

**Response envelope:**

```json
{
  "data": {
    "session_id": "uuid",
    "message_id": "uuid",
    "reply": "Markdown string…",
    "topic": "CV"
  },
  "error": null
}
```

Flutter model: `AiChatResponse` in `ai_chat_model.dart`.

### POST `/ai/chat/stream` (SSE)

**Request:** same body as `/ai/chat`

**Response:** `Content-Type: text/event-stream`

```
event: message_start
data: {"message_id":"uuid","session_id":"uuid"}

event: delta
data: {"text":"Here"}

event: delta
data: {"text":" are"}

event: done
data: {"message_id":"uuid","usage":{"tokens":120}}

event: error
data: {"code":"RATE_LIMITED","message":"Too many requests"}
```

Flutter implementation sketch:

```dart
Stream<AiStreamEvent> sendMessageStream({...}) async* {
  final request = await _dio.post(
    ApiEndpoints.aiChatStream,
    data: body,
    options: Options(responseType: ResponseType.stream),
  );
  // Parse SSE lines → AiStreamEvent
}
```

Models:

```dart
sealed class AiStreamEvent {}
class AiStreamStart extends AiStreamEvent { ... }
class AiStreamDelta extends AiStreamEvent { final String text; }
class AiStreamDone extends AiStreamEvent { ... }
class AiStreamError extends AiStreamEvent { ... }
```

## Repository interface (target)

```dart
abstract class AiRepositoryContract {
  Future<List<AiSession>> fetchSessions({int page = 1});
  Future<List<AiMessage>> fetchMessages({required String sessionId, int page = 1});

  Future<AiChatResponse> sendMessage({
    required String message,
    String? sessionId,
    AiTopic? topic,
    String? clientMessageId,
  });

  Stream<AiStreamEvent> sendMessageStream({...}); // feature-gate

  Future<void> deleteSession(String sessionId);
  Future<void> renameSession(String sessionId, String title);
  Future<void> togglePinSession(String sessionId);

  Future<AiChatResponse> regenerate({
    required String sessionId,
    required String messageId,
  });

  Future<void> cancelRequest(String requestId);
}
```

## Error mapping

| HTTP | Code | Flutter UX |
|------|------|------------|
| 401 | `UNAUTHORIZED` | Redirect to login |
| 403 | `FORBIDDEN` | "Access denied" |
| 404 | `NOT_FOUND` | Remove session from list if owned |
| 429 | `RATE_LIMITED` | Snackbar + cooldown timer |
| 502 | `PROVIDER_ERROR` | "AI unavailable, try again" |
| Network | — | Offline snackbar, Retry on message |

Map in `AiRepository` — controller only sees typed exceptions.

## Security

- JWT on every request via `Dio` interceptor
- Never log `message` content in production
- `client_message_id` prevents duplicate turns on retry
- Session ownership validated server-side on every endpoint
