## App bar (`chatbot_app_bar.dart`)

Match reference — **not** centered title with add-comment icon.

| Element | Spec |
|---------|------|
| Leading | Circular button, light grey fill, `Icons.menu` → `openDrawer()` |
| Title | **Vithey AI** teal pill — `AppColors.primary`, `borderRadius: 20`, white bold 15sp |
| Title align | **Start** after leading (not `centerTitle: true`) |
| Trailing | Circular button, `Icons.chevron_right` → `newChat()` |
| Elevation | 0, bottom `Divider` 1dp |
| Surface | `context.scheme.surface` |

```dart
PreferredSizeWidget buildChatbotAppBar({
  required VoidCallback onMenu,
  required VoidCallback onNewChat,
});
```

## Empty / suggestion state (`chatbot_suggestion_list.dart`)

**New pattern:** suggestions sit **directly above the composer**, not as a centered hero.

| Element | Spec |
|---------|------|
| Position | Column child **below** `Expanded` message area, **above** `ChatbotComposer` |
| Visibility | `!hasMessages && !isLoadingMessages` |
| Row | `InkWell` full width, padding `16h × 12v` |
| Leading icon | 24dp topic icon (e.g. `Icons.sports_basketball_outlined`) |
| Label | Muted dark grey, 15sp — one line ellipsis |
| Tap | `fillStarterPrompt(text)` + focus composer — **do not auto-send** |

## Session behavior

| Action | Behavior |
|--------|----------|
| `newChat()` | Clear messages, null `sessionId`, clear composer, close drawer — **no API** |
| Chevron `>` | Same as `newChat()` |
| First `sendMessage` | `POST /ai/chat` without `session_id`; adopt returned id |
| `selectSession` | Stale-guard with `_requestToken` |
| Drawer New Chat | Same as `newChat()` + close drawer |

## Disclaimer

| State | Show |
|-------|------|
| Empty home | Hidden (matches reference) |
| Has messages | Muted 11sp below composer: *Vithey AI may make mistakes…* |

## Screen composition (`chatbot_screen.dart`)

```dart
Scaffold(
  key: scaffoldKey,
  drawer: ChatbotHistoryDrawer(...),
  appBar: buildChatbotAppBar(...),
  body: Column(
    children: [
      Expanded(child: messageListOrLoading),
      Obx(() => showSuggestions.value
          ? ChatbotSuggestionList(...)
          : const SizedBox.shrink()),
      ChatbotComposer(...),
      if (hasMessages) disclaimer,
    ],
  ),
)
```
