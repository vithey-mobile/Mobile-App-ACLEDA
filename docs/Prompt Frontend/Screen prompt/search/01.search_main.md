## Search app bar (`search_app_bar.dart`)

Facebook/Messenger pattern — **no separate title**; search field dominates:

| Element | Spec |
|---------|------|
| Leading | `Icons.arrow_back` — `Navigator.pop` |
| Field | Expanded rounded `TextField` inside grey pill |
| Fill | `context.appColors.inputFill` |
| Radius | 20–24dp full pill |
| Prefix | `Icons.search` muted |
| Suffix | `Icons.close` when query not empty — clears text + shows Recent |
| Placeholder | **Search** |
| Autofocus | `true` on screen open |
| Action | `TextInputAction.search` submits / dismisses keyboard |

```dart
PreferredSizeWidget buildSearchAppBar({
  required TextEditingController controller,
  required VoidCallback onClear,
  required ValueChanged<String> onChanged,
  required VoidCallback onSubmitted,
});
```

## Recent section (`search_recent_section.dart`)

Shown when `query.trim().isEmpty`.

| Element | Spec |
|---------|------|
| Header | **Recent** — semibold 16sp, left padding 16dp |
| Optional action | **Clear all** text button right — confirm dialog |
| List | `ListView` of recent items (users + text queries mixed or users-only per reference) |

Reference image shows **users only** with "last seen recently" — implement user recents first; text-query recents optional in `03`.

## Recent user row (`search_recent_tile.dart`)

| Zone | Spec |
|------|------|
| Avatar | `UserAvatar` 48dp circle |
| Title | `fullName` — semibold 15sp |
| Subtitle | Presence string — see below |
| Tap | Open `ProfileArgs(userId)` + bump to top of recents |
| Long press | Remove from recents |

### Presence subtitle (Facebook-style)

| State | Copy |
|-------|------|
| Online | **Active now** |
| Recently active | **last seen recently** |
| Offline with time | **last seen 2h ago** |
| Unknown | **last seen recently** *(mock default)* |

Do not fabricate precise last-seen unless server provides `last_seen_at` or presence WebSocket.

## States

| State | UI |
|-------|-----|
| Initial | Autofocus field + Recent list |
| Recent empty | **No recent searches** + subtitle *Try searching for people, posts, or jobs* |
| Loading recents | Brief shimmer (3 rows) |
| Query 1 char | Keep showing Recent; hint in field — no API yet |
| Query ≥ 2 chars | Switch to results view — `02.search_results.md` |
