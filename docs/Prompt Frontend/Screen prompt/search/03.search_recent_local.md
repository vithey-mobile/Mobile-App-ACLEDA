# 03 — Search Recent History (Local Storage)

Persist **Recent** users and queries across sessions — Facebook-style recall on empty search.

## Storage options

| Option | Use when |
|--------|----------|
| **shared_preferences** | JSON list ≤ 20 items — simplest |
| **Isar** | Unified with chat/offline cache — optional |

Default: `shared_preferences` via `SearchRecentStore`.

## Data models

```dart
class SearchRecentUser {
  final String userId;
  final String fullName;
  final String? avatarUrl;
  final DateTime visitedAt;
}

class SearchRecentQuery {
  final String query;
  final DateTime searchedAt;
}
```

## `SearchRecentStore`

```dart
class SearchRecentStore {
  static const maxUsers = 15;
  static const maxQueries = 10;

  Future<List<SearchRecentUser>> getRecentUsers();
  Future<void> addRecentUser(SearchRecentUser user); // dedupe by userId, move to top
  Future<void> removeRecentUser(String userId);
  Future<void> clearRecentUsers();

  Future<List<SearchRecentQuery>> getRecentQueries();
  Future<void> addRecentQuery(String query); // dedupe case-insensitive
  Future<void> clearRecentQueries();
  Future<void> clearAll();
}
```

## When to write recents

| Event | Action |
|-------|--------|
| Tap person result | `addRecentUser` |
| Tap person recent row | `addRecentUser` (bump timestamp) |
| Submit search (keyboard Search) | `addRecentQuery` |
| Open profile from people section | `addRecentUser` |

Do not add to recents on mere highlight/hover.

## Clear all flow

1. User taps **Clear all** on Recent header
2. Confirm dialog: **Clear recent searches?** / **This won't affect your account history.**
3. `clearAll()` + refresh UI

## Privacy

- Recents are **device-local** only
- Clear on logout: `SearchRecentStore.clearAll()`
- Clear on account switch
- Never sync recents to server without explicit product decision

## Merge display (reference alignment)

`search main.png` shows **users only** in Recent. Implementation options:

| Mode | Behavior |
|------|----------|
| **A (match image)** | Recent list = users only |
| **B (Facebook web)** | Users first, then recent text queries as chips |

**Default: Mode A** — users only in main list; recent queries as optional second section behind feature flag.

## Controller integration

```dart
@override
void onInit() {
  super.onInit();
  _loadRecents();
}

Future<void> _loadRecents() async {
  recentUsers.assignAll(await _recentStore.getRecentUsers());
}
```

## Acceptance criteria

- [ ] Recents survive app restart
- [ ] Dedupe by userId; most recent first
- [ ] Clear all with confirmation
- [ ] Cleared on logout
- [ ] Max 15 users enforced
