# 05 - Search See All

Paginated “see all” for one Search category (people / posts / jobs / videos).

## Product spec

### Quick info

| Field | Value |
|-------|-------|
| Screen ID | `search-see-all` |
| Route | `AppRoutes.searchSeeAll` (`/search/see-all`) |
| Flutter module | `lib/modules/search/search_see_all_screen.dart` |
| Backend service(s) | `user-profile-service`, `content-service` |
| Auth required | Yes |

### Purpose

Expand a Search results section beyond the preview limit of 3.

### Open from

- Search results → See all on a section header
