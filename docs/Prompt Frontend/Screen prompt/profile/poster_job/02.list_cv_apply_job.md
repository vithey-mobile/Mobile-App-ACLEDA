# 02 - Applicant List (Job Applications)

Poster-side list of applicants for one job post.

## Product spec

### Quick info

| Field | Value |
|-------|-------|
| Screen ID | `profile-applicants` |
| Route | `AppRoutes.jobApplicants` (`/profile/jobs/applicants`) |
| Flutter module | `lib/modules/profile/job_applicants_screen.dart` |
| Backend service(s) | `career-service`, `file-service` |
| Auth required | Yes (job poster) |
| Competition feature | Yes |

### Purpose

Show everyone who applied to the owner’s job post; open applicant detail / CV.

### Open from

- Profile Jobs tab → View applicants on a job card

### Main UI

| Element | Description |
|---------|-------------|
| App bar | Job title |
| Applicant rows | Avatar, name, status, applied time |
| Empty state | No applicants yet |

### API endpoints

| Method | Path | Notes |
|--------|------|-------|
| GET | `/job-applications?job_post_id=` | Poster-only list |
