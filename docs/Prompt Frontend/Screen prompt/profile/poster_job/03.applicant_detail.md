## Cover background

| Spec | Value |
|------|-------|
| Padding | **20px** on all sides |
| Shape | Rectangular with **rounded corners** (no wavy clip) |
| Fill | Soft teal `#7DDAD6` |
| Decor | Icons darker than fill (`#2A9E99`); **larger** than first pass |
| Height | Compact (~120dp) |

## Profile information

| Spec | Value |
|------|-------|
| Alignment | Start (left) |
| Avatar | Smaller (~40 radius), start-aligned under cover |
| Name | Larger bold (~22sp) |
| Name + **View Profile** | Same row, space-between |
| Applied position | **Bold**; tight with name; **larger gap below** before contact |
| Contact | Location + email rows, **tight** with each other |

## Experience

- Every experience item has its own timeline: teal **dot** + **vertical line** spanning that item’s title + description (N experiences → N markers).
- Content remains **two-column** (description must not flow under the date):

| Column | Content |
|--------|---------|
| Left (`Expanded`) | Title, optional organization, description (wraps) |
| Right | Date in a **light primary** rounded container; **primary** text; top-aligned |

## Education

- Icon in light primary tile; **vertically centered** in the row.
- School and date on one row with **space between** (date after school, not on the degree line).
- Degree / major on the line below.

## Curriculum Vitae

| Spec | Value |
|------|-------|
| Preview | Fixed-height; vertical scroll inside |
| Mock image | `assets/images/cv/My_CV.png` when CV exists |
| Tap | Existing View CV route |
| File name | Exact original uploaded name from application `cvFileName` (e.g. `Heng_Liza_CV.pdf`). Do not invent names from the display name. When the CV is re-uploaded, this field updates. |
| Empty | **No CV Available** |

## Accept & Reject

| Button | Style | Action |
|--------|-------|--------|
| **Accept** | Same **FilledButton** style as before; fill = `Theme.colorScheme.primary` (same teal as **View Profile**), white text | Confirm dialog → existing status update |
| **Reject** | Red `FilledButton`, white text | Confirm dialog → existing status update |

No View CV on the bottom bar.

## Typography

Larger / more prominent:

- Profile name
- Section titles: Experience, Education, Curriculum Vitae (~18sp bold)
