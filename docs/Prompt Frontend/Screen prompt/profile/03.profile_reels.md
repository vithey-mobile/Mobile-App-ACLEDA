# 03 — Profile Reels Tab

Build the **Reels** tab from `Own Profile (Video).png`.

> Shell (cover, actions, tabs): `01.profile_home.md`.

## Quick info

| Field | Value |
|-------|-------|
| Tab | Reels |
| Module | `lib/modules/profile/widgets/` |
| Prompt | `Screen prompt/profile/03.profile_reels.md` |
| Visual | `Prompt Frontend/screen image/profile/own/Own Profile (Video).png` |

## Goal

Show the owner's (or visitor's) VIDEO posts as a vertical list of cards with thumbnail, play overlay, title, description, time, and engagement actions. Match the All tab list style with **20px** screen padding (`fromLTRB(20, 16, 20, 100)`) and **start-aligned** Like / Comment / Share.

## Layout

`
┌─────────────────────────────────────┐  ← 20px screen padding
│ ┌─────────────────────────────────┐ │
│ │     [thumbnail image]           │ │
│ │           ▶ (play)              │ │
│ └─────────────────────────────────┘ │
│ CCNA                                │  Title bold
│ Design topology for a small...      │  Description muted
│ 1 week ago                          │
│ ♡ Like   💬 Comment   ↗ Share       │  Align START (not space-even)
└─────────────────────────────────────┘
`

## Card spec (`profile_reels_card.dart`)

| Element | Spec |
|---------|------|
| Thumbnail | 16:9; `cached_network_image` |
| Play overlay | Centered circle, white `Icons.play_arrow`, light scrim |
| Title | Bold 15sp, 1 line ellipsis |
| Description | Muted 13sp, max 2 lines |
| Time | Relative — e.g. `1 week ago` |
| Actions | Shared `FeedActionBar` with `alignStart: true` — same as Profile Posters (Like · Comment · Share clustered left) |
| Card | Rounded 12dp, subtle border `context.appColors.border` |
| Screen padding | List content **20px** horizontal, **16px** top — same as All tab |
| Vertical gap | ~8dp between cards |

## Data

- `GET /api/v1/users/{userId}/posts?type=VIDEO&page=&limit=`
- Use server `thumbnail_url`, `duration`, `processing_status` when available
- Engagement counts from post model (`reactionCount`, `commentCount`, `shareCount`)

## Behavior

| Action | Result |
|--------|--------|
| Tap card / thumbnail | `PostDetail` with video player |
| Like / Comment / Share | Same engagement flows as media feed (or wire stubs until shared handlers exist) |
| Tab switch | Pause any active preview |
| Scroll | Paginate at 80% |

Do not autoplay in list — thumbnail + play icon only.

## Processing states

| Status | UI |
|--------|-----|
| `READY` | Normal thumbnail |
| `PROCESSING` | Shimmer + "Processing…" |
| `FAILED` | Grey placeholder + retry |

## Owner vs visitor

| Rule | Detail |
|------|--------|
| Own | Show own Reels; empty CTA encourages upload/create |
| Visitor | Public Reels only |
| Type filter | Only `PostType.video` |

## States

| State | Copy |
|-------|------|
| Empty owner | **Create your first Reels** |
| Empty visitor | **No Reels yet** |
| Loading | List shimmer / loading widget |

## Widgets

`text
lib/modules/profile/widgets/
  profile_reels.dart           # ProfileReelsTab — same ListView padding as All
  profile_reels_card.dart      # thumbnail + meta + start-aligned actions

- [ ] Matches `Own Profile (Video).png` card structure

- [ ] Like / Comment / Share **align start**
- [ ] Play overlay centered; no list autoplay
- [ ] Only VIDEO posts render
- [ ] Pagination + processing states when data supports them
- [ ] Light/dark readable

Deliver the Profile Reels tab per this v1 prompt without regressing the profile shell.
