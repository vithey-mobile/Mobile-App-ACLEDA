## Concept

The existing CV feature already allows users to create and preview their CV. Now we want to support **multiple CV templates/styles**.

The CV should be generated automatically using the user's own information from their account and profile.

The system should:

- Read the user's account and profile data.
- Collect all relevant CV information such as personal information, contact information, education, skills, experience, projects, and other available profile data.
- Place the user's information into the selected CV template automatically.
- Keep the user's information the same while allowing different CV designs/templates.
- Do not require users to re-enter information that already exists in their account/profile.
- Support the different layouts and sections shown in the provided template images.
