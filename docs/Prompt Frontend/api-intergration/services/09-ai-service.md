# 09 — AI Service Integration Contract

> **Target Service:** `ai-service`  
> **Direct Port:** `8089` | **Gateway Base URL:** `http://localhost:8080/api/v1/ai`  
> **Database:** `ai_db` | **Naming Convention:** `snake_case` (Jackson globally configured)

---

## 1. Chatbot Assistant

### 1.1 Send Message (Synchronous)
- **Method / Path:** `POST /api/v1/ai/chat`
- **Auth:** Bearer JWT required
- **Headers:** `Content-Type: application/json`

#### Request Schema
| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `message` | `string` | Yes | User prompt (max 4000 chars) |
| `topic` | `string` | No | `"CV"`, `"JOB"`, `"INTERVIEW"`, `"STUDENT"`, `"FINANCE"` |
| `session_id` | `string` | No | Existing session UUID (omit to start a new chat session) |
| `client_message_id` | `string` | No | Client deduplication id |

```json
{
  "message": "What should I include in my resume for a junior Flutter developer role?",
  "topic": "CV",
  "session_id": null
}
```

#### Response Schema (`200 OK`)
```json
{
  "data": {
    "session_id": "98765432-abcd-ef01-2345-6789abcdef01",
    "reply": "For a Junior Flutter Developer role, emphasize:\n\n1. **Core Dart Knowledge:** Async/await, streams, null safety.\n2. **State Management:** Riverpod, BLoC, or Provider.\n3. **Portfolio Projects:** Links to live GitHub repositories or published apps demonstrating API integration.\n4. **Clean Architecture:** Separation of domain, data, and presentation layers.",
    "topic": "CV",
    "message_id": "12345678-90ab-cdef-1234-567890abcdef",
    "request_id": "fedcba98-7654-3210-fedc-ba9876543210"
  }
}
```

### 1.2 Send Message (Server-Sent Events / SSE Streaming)
Streams tokens as they are generated by the model.

- **Method / Path:** `POST /api/v1/ai/chat/stream`
- **Auth:** Bearer JWT required
- **Accept:** `text/event-stream`

#### Event Progression
1. **`meta`**: Sent once before tokens start
   ```text
   event: meta
   data: {"request_id":"fedcba98-...","session_id":"98765432-...","user_message_id":"1234-...","topic":"CV"}
   ```
2. **`token`**: Repeated for each text chunk
   ```text
   event: token
   data: {"content":"For a "}

   event: token
   data: {"content":"Junior Flutter "}
   ```
3. **`done`**: Sent upon successful completion
   ```text
   event: done
   data: {"request_id":"fedcba98-...","session_id":"98765432-...","message_id":"assistant-msg-id","cancelled":false}
   ```
4. **`error`** (Only if generation fails):
   ```text
   event: error
   data: {"code":"AI_PROVIDER_ERROR","message":"Upstream AI service unavailable"}
   ```

---

### 1.3 Cancel In-Flight Generation
Cancels an ongoing generation if the user taps "Stop".

- **Method / Path:** `DELETE /api/v1/ai/chat/requests/{requestId}`
- **Auth:** Bearer JWT required

**Response:** `204 No Content`

---

### 1.4 Regenerate Assistant Reply
- **Method / Path:** `POST /api/v1/ai/messages/{messageId}/regenerate`
- **Auth:** Bearer JWT required

Returns updated `ChatResponse` in `{ "data": { ... } }`.

## 2. CV Enhancement & Suggestions

Automated AI review of CV sections (summary, experience, skills).

- **Method / Path:** `POST /api/v1/ai/cv/suggest`
- **Auth:** Bearer JWT required

### Request Schema
| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `section` | `string` | Yes | CV section name e.g. `"SUMMARY"`, `"EXPERIENCE"`, `"PROJECTS"` |
| `original_text` | `string` | Yes | User's draft text (max 8000 chars) |
| `cv_file_id` | `string` | No | Optional reference to uploaded CV file in `file-service` |

```json
{
  "section": "EXPERIENCE",
  "original_text": "I worked on mobile app for university project using flutter and acleda api.",
  "cv_file_id": null
}
```

### Response Schema (`200 OK`)
```json
{
  "data": {
    "suggested_text": "Architected and delivered a cross-platform mobile banking solution for AUB using Flutter and Spring Boot, integrating secure REST APIs and real-time WebSocket messaging.",
    "interaction_id": "3456789a-bcde-f012-3456-7890abcdef01"
  }
}
```
